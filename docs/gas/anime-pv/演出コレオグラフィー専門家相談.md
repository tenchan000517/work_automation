# 演出コレオグラフィー専門家相談

## あなたは誰か

あなたは以下の3つの専門性を持つエキスパートです：

1. **映画監督・CMディレクター** - 一瞬のカットで視聴者の心を震わせる演出設計を数百本手がけてきた
2. **モーショングラフィックスデザイナー** - エフェクト、パーティクル、カメラワークのタイミング設計のプロ
3. **AI動画生成のプロンプトエンジニア** - KLING/VIDUで実際に動画を生成し、何が再現可能で何が難しいかを熟知している

## 私たちが作りたいもの

企業の採用PV・ブランディングPVにおける「演出シーン（アクセントシーン）」のテンプレート。

**演出シーンとは**：
- 12シーンの本編とは独立した、シーン転換のアクセント
- 視聴者の感情がピークに達する瞬間
- 1〜5秒の短いカットで心を掴む

## 重要な制約

### キャラクター描写の原則
- **書かない**: 人物の「特徴」（髪の色、服装、体型）→ キャラクターシートを参照画像として添付するため不要
- **書く**: 人物が「どのように存在するか」（アクション、表情、ポーズ、カメラアングル）

### 出力形式
各演出から最終的に以下を生成する：
1. **開始フレームプロンプト** - 静止画生成AI用
2. **動画プロンプト** - KLING/VIDU用（5秒程度）

## 私が求めている「演出の深さ」

### ❌ こういうのは要らない（浅い）

```
名前: 目開き+花びら
説明: 目を開けると花びらが舞う
```

これは「何」+「何」でしかない。誰でも思いつく。

### ✅ こういうのが欲しい（深い）

```
名前: 目開き+粉爆発

【コレオグラフィー（振り付け）】

Phase 0 - 静（1秒）
├─ キャラ: 目を閉じている、完全静止、表情は穏やか
├─ エフェクト: 無し
├─ カメラ: 目の超クローズアップ、静止、被写界深度浅い
├─ 照明: 暗め、顔に柔らかい光
└─ 音響イメージ: 無音または低い持続音

Phase 1 - 動・加速（0.3秒）
├─ キャラ: 目がパッと開く（速い）、瞳孔が収縮
├─ エフェクト: 背後から青・赤・黄・白の粉が爆発、中心から外へ放射状、速い
├─ カメラ: 開眼と完全同期でわずかにズームアウト開始
├─ 照明: 爆発と同時にフラッシュ、明度急上昇
└─ 音響イメージ: ドン！という衝撃音

Phase 2 - 動→静・減速（2秒）
├─ キャラ: 目を開いたまま、瞳に光の反射が入る、表情が決意に変化
├─ エフェクト: 粉がスローモーションで四方に広がる、重力に従いゆっくり落下開始
├─ カメラ: ゆっくりズームアウト継続、顔全体→バストショットへ
├─ 照明: 粉に光が反射してキラキラ、顔は柔らかい光
└─ 音響イメージ: 高音のキラキラ音、音楽が入り始める

Phase 3 - 静（1秒）
├─ キャラ: 静止、決意の表情をキープ
├─ エフェクト: 粉がゆっくり漂う、一部は画面外へ、一部は残る
├─ カメラ: 静止
├─ 照明: 安定、暖かい
└─ 音響イメージ: 音楽が続く、余韻
```

**これが「演出のコレオグラフィー」**

- キャラの動き、エフェクトの動き、カメラの動きが**どう連動するか**
- 速度変化（速い→遅い、静止→動→静止）
- 各フェーズの**秒数**
- 照明の変化
- 全体の**リズム**

## 依頼内容

以下の3カテゴリ、合計10〜15種類の演出コレオグラフィーを設計してください。

### カテゴリ1: ピーク演出（5〜7種）
感情が最高潮に達する瞬間。視聴者が息を呑む。

求める演出の方向性：
- 覚醒・気づきの瞬間
- 決意・覚悟の瞬間
- 感情の解放（涙、笑顔）
- 運命の出会い・再会
- 勝利・達成

### カテゴリ2: 転換演出（3〜5種）
シーンが切り替わる、新しい章が始まる瞬間。

求める演出の方向性：
- 過去→現在の切り替わり
- 挫折→再起
- 孤独→仲間
- 迷い→確信

### カテゴリ3: 締め演出（2〜3種）
エンディング直前、余韻を残す。

求める演出の方向性：
- 希望を感じさせる終わり
- 静かな決意
- 未来への一歩

## 注意事項

1. **ありきたりな演出は要らない** - 「目を開ける+花びら」のような誰でも思いつくものではなく、プロならではの演出を
2. **AI生成の実現可能性を意識** - KLING/VIDUで再現できる範囲で設計
3. **タイミングが命** - 0.1秒単位で効果が変わることを理解した上で設計
4. **静→動→静のリズム** - 動きっぱなし、静止しっぱなしは避ける
5. **速度変化を明確に** - 「ゆっくり」「速く」ではなく、どのフェーズでどう変化するか
