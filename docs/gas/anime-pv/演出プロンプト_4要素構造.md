# 演出プロンプト 4要素構造

演出を4要素で分解し、再現性と応用性を高めた設計書。

---

## 4要素の定義

| 要素 | 定義 | 例 |
|------|------|-----|
| **アクション** | 人物の動き | 目を開く、振り向く、手を伸ばす |
| **オブジェクト** | 動くもの自体 | 花びら、光の粒子、衝撃波、涙、扉 |
| **エフェクト** | オブジェクトの動き方 | 舞う、上昇する、爆発的に広がる、流れ落ちる |
| **カメラワーク** | キーフレーム + キーイング + フォーカス（時間軸） | 下記参照 |

### カメラワークの構成

| 要素 | 内容 |
|------|------|
| **キーフレーム** | 何が起こるか（カメラ位置、状態） |
| **キーイング** | どう変化するか（緩急、速度感） |
| **フォーカス** | 何を見せるか（注目対象の切り替え） |

### キーイングパターン

| パターン | 速度感 | 使用場面 |
|---------|--------|----------|
| **静・溜め** | ゆっくり、じわじわ | 緊張の構築、予兆 |
| **ピーク** | 一気に、瞬間的 | クライマックス、転換点 |
| **加速** | 徐々に速く | 期待感、追い込み |
| **物理準拠** | 自然な速度 | 落下、衝撃など物理的動き |
| **スロー・余韻** | 引き延ばし | 美しさ強調、感情浸透 |
| **静・着地** | 穏やかに収束 | 終わり、安定 |

## A. そのまま使える（6種）

---

### A-1. 扉開放

| 要素 | 内容 |
|------|------|
| **アクション** | 暗闘で探す → 扉を押し開ける → 光の中へ踏み出す |
| **オブジェクト** | 扉（光の輪郭）、光、風 |
| **エフェクト** | 扉が開く、光が溢れ出す、風が吹き込む、髪・服がなびく |

**カメラワーク**:
```
0-1.3s ── オーバーショルダー、暗い空間
          【静・溜め】不安、探索
          フォーカス: 人物の背中・表情

1.3-1.9s ─ 扉発見、近づく
          【加速】期待感
          フォーカス: 扉の輪郭へ移動

1.9-2.7s ─ 扉を押す、開き始める
          【ピーク】光が一気に溢れる
          フォーカス: 扉と光

2.7-3.7s ─ 扉全開、光と風
          【物理準拠】風の速さで
          フォーカス: シルエットになった人物

3.7-5s ─── 踏み出す、新世界
          【スロー・余韻】美しい空を見せる
          フォーカス: 新世界の風景 → 人物
```

|------|------|
| **アクション** | 目を閉じている → ゆっくり開く |

          フォーカス: 開いていく目 → 瞳

3-4s ──── 固定
          【静・着地】完全に開いた目、光が映る
          フォーカス: 瞳の中の反射
```

# 改善候補版（9種）

### C-1. 涙

| 要素 | 内容 |
|------|------|
| **アクション** | 目を閉じる/開く → 涙が流れる → 表情変化 |
| **オブジェクト** | 涙の粒、波紋 |
| **エフェクト** | 涙が溜まる → 粒になって落ちる → 着地で波紋 |

**カメラワーク（改善版）**:
```

          【静・溜め】涙がじわじわ溜まる

          【物理準拠】落下速度は自然に
          フォーカス: 涙の粒（追従）

2.5-4s ── 引き
          【スロー・余韻】着地、波紋が広がる
          フォーカス: 波紋 → 全体へ
```

**改善プロンプト案**:
```
single spherical tear drop forming,
