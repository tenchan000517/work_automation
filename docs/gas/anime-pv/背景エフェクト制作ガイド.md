# 背景エフェクト制作ガイド

## コンセプト

背景エフェクトを人物動画と分離し、後で合成することで精度向上を図る。

```
①背景エフェクト動画（本ガイドで制作）
        ＋
②人物動画（クロマキー・GASで生成）
        ↓
  PremierePro/PowerDirector で合成
```

## エフェクトの基本設計思想

**重要**: エフェクトは一定ではなく、人物のアクションと連動して変化する

```
[静] → [爆発] → [ピーク] → [余韻]
 ↓       ↓        ↓        ↓
無/微小  急激な   最大の    減衰
の動き   立ち上がり 表現     スロー
```

### タイミングガイドライン（5秒動画の場合）

| フェーズ | 時間 | 説明 |
|---------|------|------|
| 静 | 0.0 - 1.0秒 | 静止または微小な動き |
| 爆発 | 1.0 - 1.5秒 | 人物アクション開始に合わせて急激に変化 |
| ピーク | 1.5 - 3.0秒 | 最大の表現、ダイナミックな動き |
| 余韻 | 3.0 - 5.0秒 | 徐々に減衰、スローモーション的表現 |

### 1. 花びら舞う（petals_swirl）

**演出意図**: 覚醒、目覚め、新たな始まり

#### 開始フレームプロンプト
```
Black background with scattered cherry blossom petals frozen in mid-air,
completely still, petals distributed across frame but not moving,
some petals near edges of frame, soft pink and white petals,
backlighting creating silhouettes,
no motion blur, crisp edges,
centered composition leaving space for character overlay,
8K quality, cinematic
```

#### 終了フレームプロンプト
```
Black background with cherry blossom petals gently floating downward,
sparse distribution, petals moving slowly in gentle spiral patterns,
soft dreamy atmosphere, subtle motion blur on petals,
warm soft lighting, petals fading toward edges,
peaceful settling motion,
centered composition,
8K quality, cinematic
```

#### 動画プロンプト
```
Black background, cherry blossom petals animation.

TIMING:
- 0-1s: Petals completely frozen in air, no movement, suspended
- 1-1.5s: Sudden explosive burst from center, petals rapidly swirl outward
- 1.5-3s: Peak intensity, petals dancing wildly in circular vortex pattern,
  some petals flying toward camera, others spiraling away
- 3-5s: Gradual slowdown, petals begin gentle descent,
  movement becomes dreamy and ethereal, slow motion feeling

CAMERA: Static centered shot, no camera movement,
allowing clean character overlay

KEYING: Pure black background (#000000),
petals have soft edges but clear separation from background

MOTION: Organic swirling pattern, never uniform,
variation in petal size and rotation speed

5 seconds, seamless loop friendly ending,
high quality particle animation, 8K
```

## 制作時の注意事項

### キーイング（合成用）の重要ポイント

1. **背景は純粋な黒 (#000000)** を使用
2. エフェクトのエッジは**ソフトフォールオフ**で
3. **スクリーン合成**または**加算合成**を想定
4. 画面中央に**キャラクター配置スペース**を確保

### タイミング同期の設計

人物アクションとの同期ポイント:

| 人物アクション | エフェクト反応タイミング |
|---------------|----------------------|
| 目を開ける | 1.0秒で爆発開始 |
| 振り向く | 0.8秒で変化開始 |
| 立ち上がる | 1.2秒で上昇開始 |
| 微笑む | 1.0秒でピーク |

### ファイル命名規則

```
effect_[ID]_[version].mp4
effect_petals_swirl_v1.mp4
effect_light_particles_v2.mp4
```

### 推奨出力設定

- 解像度: 1920x1080（16:9）または 1080x1920（9:16）
- フレームレート: 30fps
- コーデック: H.264 / ProRes 422
- 長さ: 5秒（必要に応じて調整）

## 合成ワークフロー

```
1. 背景エフェクト動画をタイムラインに配置
2. 人物動画（クロマキー）を上のレイヤーに配置
3. 人物のクロマキー処理（緑背景を透明に）
4. タイミング調整（人物アクションの開始点とエフェクト爆発点を合わせる）
5. 必要に応じてエフェクトの不透明度・ブレンドモード調整
6. 書き出し
```
