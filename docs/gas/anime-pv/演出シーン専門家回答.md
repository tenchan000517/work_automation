# 演出シーン専門家回答

## 専門家1: KLING/VIDU 動画生成AIプロンプトエキスパート

### 動画プロンプトの最適構造

```
[スタイル/画質] + [主要アクション] + [カメラワーク] + [環境効果] + [雰囲気/感情] + [技術指定]
```

**推奨順序**:
1. **スタイル基盤**: 画風は最初に（外部から注入される）
2. **主要アクション**: 最も重要な動き（動詞で始める）
3. **カメラワーク**: 動きの種類と速度を明示
4. **環境効果**: パーティクル、光、風など
5. **感情トーン**: 雰囲気を補強
6. **技術指定**: 品質、速度

### 効果的なキーワード集

**動きの表現**:
- `slowly` / `gradually` - ゆっくり（感情的シーン）
- `suddenly` / `abruptly` - 突然（インパクト）
- `smoothly` / `fluidly` - 滑らかに
- `trembling` / `shaking` - 震える（感情）
- `gentle` / `soft` - 優しく

**カメラワーク**:
- `slow zoom in on face` - 顔へゆっくりズーム
- `camera slowly pulling back` - ゆっくり引き
- `orbit around subject` - 被写体を回り込む
- `dolly in` - ドリーイン（前進）
- `crane shot rising` - 上昇クレーン
- `static shot with subtle movement` - 固定+微動

**効果的な動き指定**:
- `eyes slowly opening, revealing [emotion]` - 目を開ける
- `turning head toward camera, hair flowing` - 振り向き
- `reaching hand forward, fingers spreading` - 手を伸ばす
- `single tear rolling down cheek` - 涙が流れる
- `lips curving into a gentle smile` - 微笑み

### 注意点

1. **過剰な動きを避ける**: 1プロンプト = 1メインアクション
2. **具体的な秒数**: `over 3 seconds` など指定
3. **ループを避ける**: `non-looping, single action` を追加
4. **物理を意識**: 髪、服、パーティクルの動きは自然に

## 専門家2: Nanobanana 画像生成AIプロンプトエキスパート

### キャラクター一貫性を保つ構造

```
[スタイル] + [構図/カメラ] + [キャラクター状態] + [表情詳細] + [環境効果] + [照明] + [品質] + [除外項目]
```

**重要原則**:
- キャラクターの「特徴」は書かない（参照画像で解決）
- キャラクターの「状態」を詳細に書く

### 表情・感情キーワード

**目の表現**:
- `eyes half-closed, dreamy gaze` - 夢見がち
- `eyes wide open in realization` - 気づきの瞬間
- `eyes filled with tears, not yet falling` - 涙をためる
- `eyes looking up with hope` - 希望を見上げる
- `eyes gently closed, peaceful` - 穏やかに閉じる
- `eyes meeting the viewer` - 視線が合う

**表情の微細な描写**:
- `slight smile forming at the corner of lips` - 口角が上がる
- `determined expression, jaw slightly set` - 決意の表情
- `vulnerable expression, eyebrows slightly raised` - 繊細な表情
- `serene expression, complete calm` - 穏やかな表情

### 構図・カメラアングル

**インパクトのある構図**:
- `extreme close-up on eyes, face filling frame` - 目の超アップ
- `low angle looking up at subject` - 煽り（力強さ）
- `high angle looking down gently` - 俯瞰（繊細さ）
- `profile view with dramatic lighting` - 横顔+ドラマチック光
- `three-quarter view, slight head tilt` - 斜め3/4

### 背景効果の組み込み

**効果レイヤー**:
```
[前景効果] + [キャラクター] + [後景効果] + [光源]
```

例:
- `soft bokeh in foreground, character in sharp focus, cherry blossom petals floating in background, backlit by warm sunlight`
- `lens flare partially obscuring frame, face illuminated, particles of light floating around`

### ネガティブプロンプト推奨

```
text, watermark, signature, blurry, low quality, deformed, multiple people, extra limbs, bad anatomy, cropped, out of frame
```

## 専門家3: 映像クリエイター（CM/映画監督）

### ピーク演出パターン TOP 10

#### 1. 「覚醒の目開き」（The Awakening）
- **心理効果**: 新しい自分の始まり、気づき、覚醒
- **構成**: 閉じた目 → ゆっくり開く → 瞳に光が映る
- **カメラ**: 超クロースアップ、微かにズームアウト
- **照明**: 瞳に反射する光源、キャッチライト重要
- **使用場面**: ストーリーの転換点、主人公が決意する瞬間

#### 2. 「運命の振り向き」（The Turn）
- **心理効果**: 未知との遭遇、新しい道への決意
- **構成**: 背中 → 振り向き → 正面
- **カメラ**: 静止、被写体の動きで緊張感
- **照明**: 振り向いた瞬間にバックライト、レンズフレア
- **使用場面**: 新章の始まり、決意の瞬間

#### 3. 「希望への手」（Reaching Out）
- **心理効果**: 希望、夢への一歩、繋がり
- **構成**: 手を伸ばす → 光に向かって → 指先が光に触れる
- **カメラ**: ローアングル、手と顔の両方を捉える
- **照明**: 手の先に光源、シルエット効果
- **使用場面**: クライマックス、希望の象徴

#### 4. 「解放の涙」（The Release）
- **心理効果**: カタルシス、感情の解放
- **構成**: 目に涙がたまる → 一筋流れる → 表情が変わる
- **カメラ**: 極めてスロー、涙の軌跡を追う
- **照明**: 涙に光が反射、宝石のように
- **使用場面**: 感動のピーク、長い苦悩の終わり

#### 5. 「歓喜の微笑み」（The Smile）
- **心理効果**: 喜び、安堵、幸福
- **構成**: 真顔 → 口角が上がる → 満面の笑み
- **カメラ**: ミディアムクローズアップ、わずかにプッシュイン
- **照明**: 暖かい光、ソフト
- **使用場面**: ハッピーエンド、問題解決後

#### 6. 「決意の一歩」（The First Step）
- **心理効果**: 勇気、前進、覚悟
- **構成**: 静止 → 足を踏み出す → 風が吹く
- **カメラ**: ローアングル、足から顔へティルトアップ
- **照明**: 逆光、シルエット→顔が照らされる
- **使用場面**: 新しい旅立ち、挑戦の始まり

#### 7. 「邂逅の瞬間」（The Encounter）
- **心理効果**: 運命、繋がり、出会い
- **構成**: 二人の視線が交差 → 時が止まる
- **カメラ**: 交互のクローズアップ、または2ショット
- **照明**: 二人を包む柔らかい光
- **使用場面**: 重要な出会い、再会

#### 8. 「静寂からの解放」（Breaking Silence）
- **心理効果**: 抑圧からの解放、声を上げる
- **構成**: 黙っている → 口を開く → 叫ぶ/話す
- **カメラ**: プッシュイン、動きに合わせて加速
- **照明**: 暗→明への変化
- **使用場面**: 告白、主張、転換点

#### 9. 「空を見上げる」（Looking Up）
- **心理効果**: 希望、可能性、新しい視点
- **構成**: うつむき → 顔を上げる → 空を見上げる
- **カメラ**: 顔に寄り添い、一緒に上を向く
- **照明**: 上からの光が顔を照らす
- **使用場面**: 絶望からの回復、新しい始まり

#### 10. 「花びらの中で」（Amidst Petals）
- **心理効果**: 美しさ、儚さ、新しい季節
- **構成**: 花びらが舞う中に立つ → 一枚をキャッチ
- **カメラ**: ゆっくり回り込み、被写体を中心に
- **照明**: 柔らかい逆光、花びらが透ける
- **使用場面**: 美しい瞬間、季節の変わり目

### カメラワーク・照明の黄金律

1. **感情の高まり = カメラが近づく**
2. **解放感 = カメラが引く/上昇**
3. **緊張感 = カメラ静止、被写体が動く**
4. **希望 = 光源は上/前方**
5. **過去/内省 = 柔らかい光、影多め**

### 背景効果の効果的な使い方

| 効果 | 心理的意味 | 使用タイミング |
|------|-----------|--------------|
| 花びら | 美しさ、儚さ、新しい始まり | 春、転換点 |
| 光の粒子 | 希望、神聖、夢 | ピーク、啓示 |
| 風 | 変化、決意、自由 | 決断の瞬間 |
| 雨 | 浄化、悲しみ、再生 | 感情の解放前 |
| 雪 | 静寂、純粋、終わり | 終章、静かな決意 |
| 夕日 | 終わり、郷愁、約束 | エンディング |

### 避けるべきクリシェ

1. **スローモーション多用** - 本当に必要な1-2箇所のみ
2. **過剰なレンズフレア** - 1シーン1回まで
3. **説明的すぎる演出** - 視聴者の想像力を信じる
4. **全部見せる** - 一部を隠すことで想像を掻き立てる
