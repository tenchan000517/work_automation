## キャラクターシート作成プロンプト

### 使い方

1. 使用したいスタイルのプロンプトをコピー
2. `【】`内の項目を実際の情報に置き換える → [指示用語を見る](#指示用語リファレンス)
3. 画像生成AIに貼り付けて実行

**タブの使い分け:**
- **テキスト版**: 新規でキャラクターを生成する場合
- **画像参照版**: 既存のキャラクターシートを参照して別バージョンを生成する場合

## 使い方

### Step 1: スタイルを選ぶ

クライアントの業種・雰囲気に合わせてスタイルを選択します。

| 業種・目的 | おすすめスタイル |
|-----------|----------------|
| 採用PV（感動系） | 新海誠風、ジブリ風 |
| 製造業（熱い系） | 鳥山明風、エヴァンゲリオン風 |
| IT・テック系 | サイバーパンク風、エヴァンゲリオン風 |
| 説明動画・SNS | デフォルメ、ピクサー/3D風 |
| ブライダル・美容 | 水彩画風、新海誠風 |
| 老舗・伝統企業 | 90年代アニメ風、ジブリ風 |

### Step 2: キャラクターシートを作成

1. 選んだスタイルの「キャラクターシート作成プロンプト」から「テキスト版」をコピー
2. 【】内を実際の情報に置き換え → [指示用語を見る](#指示用語リファレンス)
3. Gemini 3 Pro Image等で生成
4. 生成されたシートを保存（以降の参照用）

### Step 3: 開始フレームを作成

1. 同じスタイルの「開始フレーム作成プロンプト」から「画像参照版」をコピー
2. キャラクターシートを参照画像として添付
3. 【】内にシーン情報を記入 → [指示用語を見る](#指示用語リファレンス)
4. 画像生成AIで実行

### Tips

- **キャラクター一貫性**: 必ずキャラクターシートを参照画像として添付
- **品質向上**: `high quality`, `detailed`, `masterpiece` などを追加
- **アスペクト比**: 動画用は必ず `16:9` を指定
- **ネガティブプロンプト対応AI**: `low quality, blurry, distorted` などを除外指定
