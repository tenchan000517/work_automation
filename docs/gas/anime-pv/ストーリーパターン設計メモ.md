## 確定した要素

### 1. 感情カーブ（7種類）

```
1. V字回復型（新卒採用推奨）
   -3 → -4 → -5 → -3 → 0 → +2 → +5 → +4 → +3 → +4 → +5 → +5
   用途：「苦しみからの脱出」を描く

2. 階段上昇型（サービス紹介/高卒採用推奨）
   -2 → -2 → -1 → 0 → +1 → +2 → +4 → +3 → +4 → +4 → +5 → +5
   用途：「徐々に良くなる」を描く

3. 波動型（会社紹介推奨）
   0 → -2 → -1 → +1 → -1 → +2 → +5 → +3 → +2 → +3 → +4 → +5
   用途：「試練と成長」を描く

4. 発見型（技術紹介推奨）
   0 → +1 → 0 → -1 → 0 → +1 → +5 → +4 → +4 → +5 → +5 → +5
   用途：「謎が解ける瞬間」を描く

5. 共鳴型（インナーブランディング推奨）
   +1 → 0 → -1 → +1 → +2 → +3 → +5 → +4 → +5 → +5 → +5 → +5
   用途：「気づきと誇り」を描く

6. 再生型（中途採用推奨）
   -4 → -5 → -4 → -2 → -1 → +1 → +4 → +3 → +4 → +5 → +5 → +5
   用途：「人生の転換」を描く

7. 平坦高揚型（展示会/BtoB専用）
   +1 → +2 → +2 → +3 → +3 → +4 → +4 → +5 → +5 → +5 → +5 → +5
   用途：「良い→もっと良い」ネガティブなし
```

### 2. 構造ルール

- 谷（最低値）→ シーン1-5の間に配置
- ピーク（最高値）→ シーン7に配置
- 終わり → +4以上で終わる

### 3. ナレーション配置（参考程度）

- 最大4シーン程度
- 8シーン以上は映像のみ
- ※後から編集可能なので参考程度

## シーン作成の要素（別軸・検討中）

### オープニング手法（3秒ルール）
```
A. 衝撃型：予想外の映像から始める
B. 共感型：ターゲットの「あるある」な苦しみを見せる
C. 美的魅了型：圧倒的に美しい映像から始める
D. 問いかけ型：視聴者の心に直接問いかける
```

### ピーク手法（30秒の壁）
```
A. 逆転：ネガティブ→突然の転換
B. 達成：努力の積み重ね→成功
C. 発見：探求→真実の開示
D. 救済：孤独→助けの手
```

### 映像表現手法（12種類）
※スタイル側で扱う可能性あり

**基本8種**
1. 表情クローズアップ ★5
2. 手元表現 ★4
3. 光の演出 ★5
4. 色彩変化 ★5
5. 物の対比 ★4
6. 身体の変化 ★3
7. 環境の変化 ★5
8. 時間の圧縮 ★5

**アニメ専用4種**
9. メタファー具現化 ★5
10. 空間歪曲 ★5
11. シンボル反復 ★4
12. トランジション演出 ★5

## 4つの原則（専門家から）

1. **3秒ルール**：最初の3秒で視聴者を掴む
2. **30秒の壁**：30秒地点に感情のピークを配置
3. **感情の波**：暗→明の転換を設計
4. **Show, Don't Tell**：言葉ではなく映像で語る

---

1. 「B共感×A逆転×V字回復」という組み合わせは抽象的なラベルに過ぎなかった

- 映像表現手法はスタイル側で扱う可能性
