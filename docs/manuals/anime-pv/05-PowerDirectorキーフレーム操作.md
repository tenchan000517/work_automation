## 1. キーフレームとは

**キーフレーム**とは、動画編集において特定の時間における映像の状態（位置、サイズ、透明度など）を記録し、その間を自動的に補間してアニメーションを作成する機能です。

### 基本的な仕組み
- **始点キーフレーム**：アニメーションの開始位置と状態を指定
- **終点キーフレーム**：アニメーションの終了位置と状態を指定
- PowerDirectorが自動的に間を補完して滑らかな動きを生成

![キーフレームの仕組み](/images/guides/powerdirector/17-keyframe-concept.avif)

## 2. キーフレームによるスケール変更

### 操作手順

#### **ステップ1：動画クリップの選択**
1. タイムライン上でスケール変更したい動画クリップを選択します

#### **ステップ2：キーフレーム設定画面を開く**
2. タイムライン上部の「**キーフレーム**」ボタンをクリックします

![キーフレームボタン](/images/guides/powerdirector/01-keyframe-setting.png)

#### **ステップ3：キーフレーム設定ウィンドウの確認**
3. 「**キーフレームの設定**」ウィンドウが表示されます

このウィンドウで以下の設定が可能です：
- **調整**：明るさ、色調、ノイズ除去
- **クリップの属性**：位置、サイズ、回転、透明度
- **音量**：オーディオレベルの調整

#### **ステップ4：開始キーフレームの設定**
4. タイムラインスライダーを**開始位置**（例：0秒）に移動させます

![開始位置設定](/images/guides/powerdirector/04-start-keyframe.avif)

5. 「**クリップの属性**」タブを選択します

![クリップ属性選択](/images/guides/powerdirector/02-clip-property.png)

6. 変更したい項目（**位置**、**高さ**、**幅**）で「**現在のキーフレームを追加/削除**」ボタンをクリックします

7. **黄色い菱型のキーフレームマーカー**が追加されます

![キーフレームマーカー](/images/guides/powerdirector/03-keyframe-marker.avif)

#### **ステップ5：終了キーフレームの設定**
8. タイムラインスライダーを**終了位置**（例：動画の末尾）に移動させます

![終了位置設定](/images/guides/powerdirector/05-end-keyframe.avif)

9. 同じ項目（位置、高さ、幅）で再度「**現在のキーフレームを追加/削除**」をクリックします

10. プレビュー画面で映像のサイズや位置を調整します
    - **サイズ変更**：四隅のハンドルをドラッグ
    - **位置変更**：映像をドラッグ&ドロップ

![スケール調整](/images/guides/powerdirector/06-scale-adjust.avif)

#### **ステップ6：確認と調整**
11. 再生ボタンを押して、アニメーションを確認します
12. 必要に応じて、途中にキーフレームを追加して動きを調整できます

![完成イメージ](/images/guides/powerdirector/14-completed.avif)

### 注意点
- 画像のサイズや位置を変更するたびに、選択中のキーフレームが自動的に更新されます
- 複数のキーフレームを設定することで、より複雑な動きも実現できます

## 3. ズームの変更操作

ズーム効果は、上記のスケール変更と同じ手順で実現できます。特にズーム効果に焦点を当てた手順を解説します。

### 操作手順

#### **ズームイン（徐々に拡大）の場合**

1. **開始キーフレーム**（0秒地点）で、通常のサイズ（高さ=100）を設定
2. **終了キーフレーム**（終了地点）で、拡大したサイズ（高さ=150など）を設定

#### **ズームアウト（徐々に縮小）の場合**

1. **開始キーフレーム**で、拡大したサイズを設定
2. **終了キーフレーム**で、通常または縮小したサイズを設定

### 実践例：画面全体から左上の小画面へ

![ズーム例](/images/guides/powerdirector/07-zoom-example.avif)

**設定値の例：**
- 0秒地点：高さ=100（フル画面）、位置=中央
- 5秒地点：高さ=20（縮小）、位置X=0.2（左上へ移動）

## 4. スピードの変更

PowerDirectorでは、動画の再生速度を簡単に変更できます。2つの方法があります。

### 方法A：簡易スピード調整

#### **ステップ1：動画速度ボタンをクリック**
1. タイムライン上で速度を変更したいクリップを選択
2. 「**動画速度**」ボタンをクリック

#### **ステップ2：スピード調整**
3. 「**ビデオスピードデザイナー**」画面が表示されます

![ビデオスピードデザイナー](/images/guides/powerdirector/08-speed-designer.avif)

4. スライダーを調整：
   - **左に移動**：スローモーション（0.25倍、0.5倍など）
   - **右に移動**：早送り（1.5倍、2倍など）

### 方法B：スピードランプ（部分的な速度変更）

より高度な速度コントロールが可能な「**スピードランプ**」機能を使うと、1つのクリップ内で自由に速度を変更できます。

#### **ステップ1：スピードランプ画面を開く**
1. クリップを選択し、「動画速度」→「**スピードランプ**」タブを選択

#### **ステップ2：キーフレームで速度を設定**
2. タイムライン上で速度を変更したい位置にキーフレームを追加
3. 各キーフレームで速度倍率を設定

![スピードランプ設定](/images/guides/powerdirector/09-speed-ramp.avif)

**例：**
- 0-2秒：通常速度（1.0倍）
- 2-4秒：スローモーション（0.5倍）
- 4-6秒：通常速度（1.0倍）

## 5. スピードのイージング変更

イージング機能を使うと、速度変化に**緩急**をつけることができ、より自然で滑らかな映像表現が可能になります。

### イージングの種類

- **イーズイン**：ゆっくり始まって、徐々に加速
- **イーズアウト**：速く始まって、徐々に減速
- **イーズイン＆アウト**：ゆっくり始まり、徐々に加速し、最後に減速

![イージング概念図](/images/guides/powerdirector/15-easing-concept.avif)

### 操作手順

#### **ステップ1：キーフレームの設定**
1. 上記の「スピード変更」手順でキーフレームを設定します
2. ビデオスピードデザイナー画面で、速度を変更したい区間のキーフレームを作成

#### **ステップ2：イージング設定を開く**
3. キーフレームを選択します

![キーフレーム選択](/images/guides/powerdirector/10-ease-setting.avif)

4. 画面上部または右側に「**イーズイン**」「**イーズアウト**」のチェックボックスが表示されます

#### **ステップ3：イージングタイプを選択**

![イージング設定画面](/images/guides/powerdirector/11-ease-in-out.avif)

**設定パターン：**

| イージングタイプ | イーズイン | イーズアウト | 効果 |
|-----------------|-----------|-------------|------|
| イーズイン | ✓ | - | ゆっくり開始→徐々に加速 |
| イーズアウト | - | ✓ | 速く開始→徐々に減速 |
| イーズイン＆アウト | ✓ | ✓ | ゆっくり開始→加速→減速 |
| リニア（線形） | - | - | 一定速度で変化 |

#### **ステップ4：強度の調整**
5. イージングの強度を調整できる場合は、スライダーで調整します
   - **1.0**：通常の強度
   - **0.4など**：弱いイージング効果

![イージング強度調整](/images/guides/powerdirector/12-ease-strength.avif)

#### **ステップ5：プレビューと微調整**
6. 再生ボタンを押して、速度変化の滑らかさを確認します
7. 必要に応じて、イージング設定を調整します

### イージング活用例

**例1：スローモーションへの滑らかな移行**
- 開始キーフレーム（通常速度1.0倍）：イーズアウト ✓
- 終了キーフレーム（スロー0.5倍）：イーズイン ✓

**例2：急激な早送り**
- 開始キーフレーム：イージングなし
- 終了キーフレーム：イージングなし（リニア補間）

![イージング比較](/images/guides/powerdirector/16-easing-compare.avif)

## まとめ

### キーフレーム機能の基本
- **開始点と終了点**を設定し、PowerDirectorが自動的に間を補間
- 位置、サイズ、回転、透明度、速度など様々なパラメータに適用可能

### スケール・ズーム変更のポイント
- 「高さ」「幅」「位置」のキーフレームを組み合わせて設定
- 複数のキーフレームで複雑な動きも実現可能

### スピード変更の2つの方法
1. **簡易調整**：クリップ全体の速度を一括変更
2. **スピードランプ**：1つのクリップ内で部分的に速度を変更

### イージングの重要性
- 速度変化に緩急をつけることで、より自然で滑らかな映像に
- **イーズイン**：徐々に加速
- **イーズアウト**：徐々に減速
- **イーズイン＆アウト**：両方の効果を組み合わせ

---

## 実践のコツ

1. **少ないキーフレームから始める**：まず2つのキーフレームで基本を習得
2. **プレビューを繰り返す**：設定後は必ず再生して確認
3. **イージングは控えめに**：効果を入れすぎると不自然になることも
4. **保存をこまめに**：複雑な設定をする前にプロジェクトを保存
