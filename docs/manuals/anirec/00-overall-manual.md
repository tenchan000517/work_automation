# アニメPV制作 全体マニュアル

## 概要

アニメPV制作の全体フローをまとめたマニュアルです。
ヒアリングシートのメニューを使って、各フェーズの作業を進めます。

---

## 全体フロー

```
Phase 1: ヒアリング
├── 新規ヒアリングシート作成
├── 企業フォルダ作成
├── 文字起こしを整理（プロンプト生成）
└── AI出力を転記
    ↓
Phase 2: 台本生成
├── 台本生成プロンプト
└── 台本パース・保存
    ↓
Phase 3: キャラクター・シーン編集
├── キャラクター設定を編集
├── シーン構成を編集
└── エンディングを編集
    ↓
Phase 4: プロンプト生成
├── キャラクターシートプロンプト
├── シーン生成プロンプト（開始フレーム / 動画）
├── 歌詞生成プロンプト
├── SUNO BGMプロンプト
├── SUNO歌詞付き楽曲プロンプト
└── ナレーション編集
    ↓
Phase 5: エフェクトシーン作成
├── エフェクトシーンプロンプト生成
├── 開始・終了フレーム生成（AI Studio）
└── I2V動画生成（Kling / VIDU）
    ↓
Phase 6: 編集・書き出し
├── タイムラインに素材を配置
├── 音ハメ・タイミング調整
└── エクスポート → 完パケ
```

---

## Phase 1: ヒアリング

### 1-1. 新規ヒアリングシート作成

企業ごとのヒアリングシートを作成します。

**手順:**

1. ヒアリングシートを開く
2. メニュー「**アニメPV制作**」→「**1️⃣ ヒアリング**」→「**新規ヒアリングシート作成**」

![メニュー：ヒアリング](/images/anime-pv/01-menu-hearing.png)

3. ダイアログで以下を入力：

| 項目 | 必須 | 説明 |
|------|------|------|
| 企業名 | ✅ | 正式名称で入力（例: 株式会社○○） |
| 業種 | ✅ | ドロップダウンから選択 |
| 目的 | - | 応募・受注獲得など |
| 用途 | - | 新卒採用PVなど |
| ターゲット | - | 高卒学生など |
| トンマナ | - | 明るい・ポップなど |

![新規ヒアリングシート作成（初期状態）](/images/anime-pv/02-new-sheet-empty.png)

![新規ヒアリングシート作成（入力済み）](/images/anime-pv/03-new-sheet-filled.png)

4. 「**作成**」をクリック

→ 企業名のシート（タブ）が自動作成されます

---

### 1-2. 企業フォルダ作成

素材管理用のフォルダをGoogle Driveに作成します。

**手順:**

1. 作成した企業シートを選択
2. メニュー「**アニメPV制作**」→「**1️⃣ ヒアリング**」→「**企業フォルダ作成**」
3. 確認ダイアログで作成されるフォルダを確認

![フォルダ作成確認](/images/anime-pv/04-folder-confirm.png)

4. 「**OK**」をクリック

![作成完了](/images/anime-pv/05-folder-complete.png)

→ フォルダが作成され、URLがシートに保存されます

**作成されるフォルダ:**

```
[企業名]/
├── 01_人物参考/
├── 02_場所設備/
├── 03_制服装備/
├── 04_その他素材/
└── 05_生成物/
    ├── とりあえず/      ← 暫定的な生成物の一時保存用
    ├── キャラクターシート/
    ├── 開始フレーム_シーン/
    ├── 開始フレーム_エフェクト/
    ├── 動画_シーン/
    ├── 動画_エフェクト/
    ├── 完パケ/
    └── 音声/
```

![Driveフォルダ](/images/anime-pv/06-drive-folders.png)

### 1-3. 文字起こしを整理（プロンプト生成）

ヒアリングの文字起こしをAIで整理するためのプロンプトを生成します。

**手順:**

1. メニュー「**アニメPV制作**」→「**1️⃣ ヒアリング**」→「**文字起こしを整理（プロンプト生成）**」
2. 対象企業を選択
3. 文字起こしテキストを貼り付け
4. 「**シートに保存**」をクリック

![文字起こしを整理（初期状態）](/images/anime-pv/08-transcript-empty.png)

![文字起こしを整理（保存完了）](/images/anime-pv/09-transcript-saved.png)

5. 完成版プロンプトの「**コピー**」をクリック
6. Claude（またはChatGPT）に貼り付けて実行

→ AIがJSON形式でヒアリング情報を抽出します

![Claude AI出力](/images/anime-pv/10-claude-output.png)

---

### 1-4. AI出力を転記

AIが出力したJSONをシートに転記します。

**手順:**

1. メニュー「**アニメPV制作**」→「**1️⃣ ヒアリング**」→「**AI出力を転記**」
2. 転記先企業を選択
3. AIの出力（JSON）を貼り付け

![AI出力を転記（JSON貼り付け）](/images/anime-pv/11-transfer-json.png)

4. 「**解析してプレビュー**」をクリック
5. 転記内容を確認

![AI出力を転記（確認画面）](/images/anime-pv/12-transfer-confirm.png)

6. 「**転記実行**」をクリック

→ Part② AI抽出データに転記されます

![Part② AI抽出データ](/images/anime-pv/13-sheet-ai-data.png)

**転記される項目:**

| 項目 | 内容 |
|------|------|
| コアメッセージ | 視聴者に伝えたい1つのメッセージ |
| ストーリーアイデア | シナリオの概要 |
| 安全装備 | 撮影時に必要な安全装備 |
| NG要素 | 映像に含めてはいけないもの |
| 舞台・世界観 | 撮影場所、雰囲気 |
| 音声設定 | ナレーション、BGM、歌詞のイメージ |

## Phase 2: 台本生成

### 2-1. 台本生成プロンプト

AIに台本を生成してもらうためのプロンプトを作成します。
12種類のストーリーパターンと10種類のスタイルから選択できます。

**手順:**

1. メニュー「**アニメPV制作**」→「**2️⃣ 台本生成**」→「**台本生成プロンプト**」

![メニュー：台本生成](/images/anime-pv/14-menu-script.png)

2. ダイアログで以下を設定：

| 項目 | 説明 |
|------|------|
| 対象企業を選択 | ドロップダウンから企業を選択 |
| ストーリーパターンを選択 | 12種類から1つ選択 |
| スタイルを選択 | 10種類から1つ選択 |

![台本生成プロンプトダイアログ](/images/anime-pv/15-script-dialog.png)

**ストーリーパターン（12種類）:**

| パターン | テーマ | 感情の流れ | おすすめ用途 |
|---------|--------|-----------|-------------|
| 自分を見つける | 「わからない」から「見つかる」への物語 | 落ちて上がる、困っている状態、逆転 | 新卒採用、中途採用、ブランディング |
| 目標を達成する | 「問い」から「達成」への物語 | 少しずつ上がる、問いかけ、達成 | 高卒採用、サービス紹介、成長志向企業向け |
| 答えを見つける | 「謎」から「真実」への物語 | 平らから急に上がる、意外な映像、発見 | サービス紹介、技術紹介、知的好奇心を刺激したい企業 |
| 居場所を見つける | 「孤独」から「繋がり」への物語 | 少し下がってから上がる、困っている状態、出会い | 新卒採用、インナーブランディング、チーム重視企業 |
| 生まれ変わる | 「限界」から「再生」への物語 | 深く落ちて上がる、困っている状態、逆転 | 中途採用、再出発をテーマにしたい企業 |
| 壁を乗り越える | 「壁」から「突破」への物語 | 上下しながら上がる、問いかけ、達成 | 新卒採用、中途採用、挑戦をテーマにしたい企業 |
| 次のステージへ | 「良い」から「もっと良い」への物語 | ずっと上がる、美しい映像、達成 | 展示会、会社紹介、ポジティブブランディング |
| 危機を乗り越える | 「危機」から「打開」への物語 | 落ちて上がる、意外な映像、逆転 | 会社紹介、サービス紹介、ドラマチックな展開向け |
| 自分と向き合う | 「表面」から「本質」への物語 | 平らから急に上がる、美しい映像、発見 | ブランディング、インナーブランディング、哲学的企業 |
| 力を合わせる | 「バラバラ」から「一つに」への物語 | 少し下がってから上がる、問いかけ、団結 | 新卒採用、会社紹介、チームワーク重視企業 |
| 大切なものに気づく | 「わからない」から「気づく」への物語 | 少しずつ上がる、困っている状態、発見 | 新卒採用、教育的メッセージ、成長志向企業 |
| 運命が変わる | 「波乱」から「変容」への物語 | 上下しながら上がる、意外な映像、逆転 | 中途採用、会社紹介、ドラマチックな転換を描きたい企業 |

**スタイル（10種類）:**

| スタイル | 特徴 |
|---------|------|
| 新海誠風 | 繊細な光、美しい背景、感情的 |
| デフォルメ | かわいい、親しみやすい、ポップ |
| エヴァンゲリオン風 | シャープ、緊張感、インパクト |
| 鳥山明風 | 明るい、躍動感、元気 |
| ジブリ風 | 柔らかい色彩、自然、温かみ |
| サイバーパンク風 | ネオン、近未来、テック感 |
| 水彩画風 | 淡い色、芸術的、上品 |
| 90年代アニメ風 | レトロ、セル画感、ノスタルジック |
| ピクサー/3D風 | 立体的、親しみやすい、ポップ |
| 実写風 | 高品質、リアル、プロフェッショナル |

3. ストーリーパターンとスタイルを選択すると、プロンプトがプレビューに表示される

### 2-2. 台本パース・保存

AIが出力した台本JSONをシートに保存します。

**手順:**

1. メニュー「**アニメPV制作**」→「**2️⃣ 台本生成**」→「**台本パース・保存**」
2. 保存先企業を選択
3. AIの出力（JSON）を貼り付け

![台本パース・保存（JSON貼り付け）](/images/anime-pv/18-parse-input.png)

4. 「**解析してプレビュー**」をクリック
5. パース結果を確認

| 項目 | 内容 |
|------|------|
| キャラクター数 | 検出されたキャラクター数と詳細 |
| シーン数 | 総シーン数 |
| ナレーション有り | ナレーションがあるシーン数 |
| エンディング | エンディングタイプ |

![台本パース・保存（確認画面）](/images/anime-pv/19-parse-confirm.png)

6. 「**シートに保存**」をクリック

→ Part③キャラクター設定、Part④シーン構成、Part⑥処理データに保存されます

![Part⑥ 処理データ](/images/anime-pv/20-sheet-part6-data.png)

![Part③④ キャラクター設定・シーン構成](/images/anime-pv/21-sheet-character-scene.png)

|------|---------|

| Part④ シーン構成 | シーン名、時間帯、場所、演出、ムード、ナレーション、動画プロンプト、開始フレームプロンプト |
| Part⑤ エンディング | タイプ、ソースオブジェクト、最終テキスト、動画プロンプト |
| Part⑥ 処理データ | 選択スタイル、選択ストーリーパターン、台本JSON |

## Phase 3: キャラクター・シーン編集

台本パース後、細かい調整を行うための編集機能です。

**メニュー:**
```
📹 アニメPV制作 > 3️⃣ キャラクター・シーン編集
├── 👤 キャラクター設定を編集
├── 🎬 シーン構成を編集
└── 🎬 エンディングを編集
```

![メニュー](/images/anime-pv/32-menu-character-scene.png)

---

### 3-1. キャラクター設定を編集

キャラクターの詳細設定を個別に調整します。

![キャラクター設定を編集](/images/anime-pv/33-character-edit.png)

**編集項目:**
| 項目 | 説明 |
|------|------|
| 名前 | キャラクター名 |
| 性別 | 男性 / 女性 |
| 現在編 年齢 | 入社後の年齢（例: 21歳） |
| 過去編 年齢 | 学生時代の年齢（例: 18歳） |
| 髪型・髪色（英語） | プロンプト用（例: Short black hair, slightly messy） |
| 目の特徴（英語） | プロンプト用（例: Dark brown eyes） |
| 体格（英語） | プロンプト用（例: Average height, lean） |
| 過去編服装（英語） | 学生服、私服など |
| 現在編服装（英語） | 作業着、安全装備など |

**ポイント:**
- タブで「キャラクター1（主人公）」「キャラクター2（サブ）」を切替
- 髪型・目・体格・服装は**英語で入力**（プロンプト生成に使用）
- 現在編服装には**必須安全装備**を含める

---

### 3-2. シーン構成を編集

12シーンの詳細を個別に編集します。

![シーン選択グリッド](/images/anime-pv/34-scene-grid.png)

シーンをクリックすると詳細編集画面が開きます。

![シーン詳細編集](/images/anime-pv/35-scene-edit.png)

**編集項目:**
| 項目 | 説明 |
|------|------|
| シーン名 | シーンのタイトル（例: 迷いの朝） |
| 時間帯 | 過去 / 転換点 / 現在 / 未来 |
| 場所 | ロケーション（例: 自宅の部屋、早朝） |
| 登場キャラ | 出演キャラ（例: 田中隼人(18歳)） |
| 演出・動き | アクション（例: 窓辺で進路資料を見つめる） |
| ムード | 雰囲気（例: 不安、迷い、グレートーン） |
| ナレーション | セリフ（日本語） |
| 動画プロンプト（英語） | Kling AI用プロンプト |

**オプションボタン:**
- **時間帯**: 朝 / 昼 / 夕方 / 夜 / 薄暮
- **カメラ**: 固定 / 左にパン / 右にパン / ズームイン / ズームアウト / 追従 など
- **アクション**: 顔を上げる / カメラを見る / 歩く / 微笑む / 決意の表情 など

クリックで動画プロンプトに追記されます。

---

### 3-3. エンディングを編集

エンディングの演出を設定します。

![エンディングを編集](/images/anime-pv/36-ending-edit.png)

**エンディングタイプ:**
| タイプ | 説明 |
|--------|------|
| オブジェクト→ロゴ変形 | 業界関連のオブジェクトがロゴに変形 |
| ロゴアニメーション | ロゴにアニメーション効果を追加 |

**編集項目:**
- 変形元オブジェクト（オブジェクト→ロゴ変形の場合）
- アニメーションタイプ（ロゴアニメーションの場合）
- 最終テキスト（ロゴの下に表示）
- 動画プロンプト（英語）

---

### 使い方のコツ

1. **台本パース後に使う** - まず「2️⃣ 台本生成」で基本データを保存してから調整
2. **微調整が中心** - 大きな変更より細部の調整に使う
3. **英語プロンプトを確認** - 生成結果に直結するので丁寧に編集
4. **保存を忘れずに** - 編集後は「💾 保存」ボタンをクリック

## Phase 4: プロンプト生成

### 4-1. キャラクターシートプロンプト

キャラクターシート（ターンアラウンド + 表情パターン）を生成するプロンプトを作成します。

**メニュー:**
```
📹 アニメPV制作 > 4️⃣ プロンプト生成
├── 🎨 キャラクターシートプロンプト
├── 🎬 シーン生成プロンプト（開始フレーム / 動画）
└── ...（音声系は後述）
```

![メニュー](/images/anime-pv/37-menu-prompt.png)

**STEP 1: ダイアログを開く**

![ダイアログ上部](/images/anime-pv/38-character-sheet-dialog-top.png)

**生成モードを選択:**
| モード | 用途 |
|--------|------|
| 🖼️ 画像参照モード | 参照画像を添付する場合（外見は画像から取得） |
| 📝 テキスト詳細モード | 参照画像なしで生成（髪型・目・体格を詳細指定） |

**キャラクターを選択:**
- キャラ1 過去編（18歳・学生服など）
- キャラ1 現在編（21歳・作業服など）
- キャラ2（サブキャラ）

**STEP 2: スタイルを選択してプロンプト生成**

![ダイアログ下部](/images/anime-pv/39-character-sheet-dialog-bottom.png)

10種類のスタイルから選択すると、プロンプトが自動生成されます。

| スタイル | 特徴 |

### 5-3. I2V動画生成

開始フレーム → 終了フレーム をつなぐ動画を生成します。

**手順:**

1. 動画タブのプロンプトをコピー
2. Kling または VIDU を開く
3. **開始フレーム画像をアップロード**
4. **終了フレーム画像を参照として添付**
5. 動画プロンプトを入力して生成

![Kling I2V 動画生成](/images/anime-pv/59-effect-video-generate.png)

**保存先:** `05_生成物/動画_エフェクト/`

**動画プロンプトの構造:**

```
[0-2.0s] 目を閉じた状態から徐々に開く、まぶたがゆっくり上がる
★[2.0s] 爆発の瞬間★ 目が完全に開くと同時にエフェクトが爆発
[2.0-4.5s] エフェクトが放射状に広がり続ける、スローモーション
Negative: 顔の前にパウダーなし、瞬きなし
```

> **重要な教訓（I2V生成のポイント）:**
> - ✅ `from behind character` が決め手。中央からではなく背後から出現
> - ✅ 動画プロンプトは**動きのみに集中**。デザイン・色・質感は終了フレームに任せる
> - ✅ シンプルな構造（時間軸 + 動きの指示のみ）
> - ❌ `from center` → 画面中央から新しいオブジェクトが出現してしまう
> - ❌ デザイン詳細指定 → 終了フレームと競合して不安定に
> - ⚠️ I2Vでカメラワーク（ズームアウト）は安定しない → 動画編集ソフトで後処理

## 応用編: エフェクトシーンで音ハメ

エフェクトシーンをBGMのビートに合わせると、よりインパクトのある映像になります。

**音ハメのポイント:**

1. **爆発タイミングをビートに合わせる**
   - 目を開く: 2.0秒で爆発 → BGMのサビ開始2秒前に配置
   - 顔を上げる: 1.3秒で爆発 → BGMのサビ開始1.3秒前に配置

2. **キーフレームでズームアウトを追加**
   - I2Vではズームアウトが安定しない → 編集ソフトで後処理
   - 爆発の瞬間からズームアウト開始

3. **スローモーションの活用**
   - エフェクト爆発後をスローモーションに
   - タイムリマップで緩急をつける

## トラブルシューティング

### シートが作成されない

- 企業名が空欄でないか確認
- 業種が選択されているか確認

### フォルダ作成でエラーが出る

- Drive APIサービスがGASに追加されているか確認
- Apps Scriptエディタ → サービス → 「+」→ Drive APIを追加

### JSON解析エラー

- JSONの形式が正しいか確認
- コードブロック（```json）で囲まれていても自動除去されます
