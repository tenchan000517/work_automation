# 専門家への質問と回答

## 質問1: 4つの原則をAIへの指示としてどう表現するか

### 質問文
```
私たちは企業PV制作のためのAI台本生成システムを開発しています。

【システム仕様】
- 尺：1分程度のショート動画
- 構成：12シーン + エンディング

【悩み】
皆さんが提唱された4つの原則を、AIへの指示としてどう表現すればいいかわかりません。

1. 3秒ルール（最初の3秒で視聴者を掴む）
2. 30秒の壁（30秒地点に感情のピークを配置）
3. 感情の波（暗→明の転換を設計）
4. Show, Don't Tell（言葉ではなく映像で語る）

これらを、AIが台本を書く際に理解して実行できる「指示文」として、どう表現すればいいですか？
```

### 回答（要約）

#### 3秒ルール → 4つの手法として選択肢化
```
A. 衝撃型：予想外の映像から始める
B. 共感型：ターゲットの「あるある」な苦しみを見せる
C. 美的魅了型：圧倒的に美しい映像から始める
D. 問いかけ型：視聴者の心に直接問いかける
```

#### 30秒の壁 → 4つのパターンとして選択肢化
```
A. 逆転：ネガティブ→突然の転換
B. 達成：努力の積み重ね→成功
C. 発見：探求→真実の開示
D. 救済：孤独→助けの手
```

#### 感情の波 → 7つのカーブパターンとして数値化
```
1. V字回復型：-3 → -4 → -5 → -3 → 0 → +2 → +5 → +4 → +3 → +4 → +5 → +5
2. 階段上昇型：-2 → -2 → -1 → 0 → +1 → +2 → +4 → +3 → +4 → +4 → +5 → +5
3. 波動型：0 → -2 → -1 → +1 → -1 → +2 → +5 → +3 → +2 → +3 → +4 → +5
4. 発見型：0 → +1 → 0 → -1 → 0 → +1 → +5 → +4 → +4 → +5 → +5 → +5
5. 共鳴型：+1 → 0 → -1 → +1 → +2 → +3 → +5 → +4 → +5 → +5 → +5 → +5
6. 再生型：-4 → -5 → -4 → -2 → -1 → +1 → +4 → +3 → +4 → +5 → +5 → +5
7. 平坦高揚型：+1 → +2 → +2 → +3 → +3 → +4 → +4 → +5 → +5 → +5 → +5 → +5
```

#### Show, Don't Tell → 映像表現手法12種類として具体化
```
基本8種：
1. 表情クローズアップ
2. 手元表現
3. 光の演出
4. 色彩変化
5. 物の対比
6. 身体の変化
7. 環境の変化
8. 時間の圧縮

アニメ専用4種：
9. メタファー具現化
10. 空間歪曲
11. シンボル反復
12. トランジション演出
```

#### 構造ルール
- 谷（最低値）→ シーン1-5の間に配置
- ピーク（最高値）→ シーン7に配置
- 終わり → +4以上で終わる
- セリフは最大4シーン、8シーン以上は映像のみ

## 質問2: アニメPVとの相性、業種対応

### 質問文
```
先ほどの回答をもとに、より精度を上げたいです。

【私たちのシステムの特性】
- アニメーションPV（実写ではない）
- 企業ごとに業種・目的・用途・ターゲットが異なる
- AIが企業情報を元に台本を自動生成

【確認したいこと】

1. パターンの網羅性
2. アニメーションPVとの相性
3. 業種による変動への対応
```

### 回答（要約）

#### 用途別推奨パターン
```
新卒採用(大卒) → B共感型 × A逆転 × V字回復
高卒採用 → C美的魅了 × B達成 × 階段上昇
中途採用 → B共感型 × D救済 × 再生型
会社紹介 → A衝撃型 × C発見 × 波動型
サービス紹介 → B共感型 × A逆転 × 階段上昇
展示会 → Eループ × E連続驚嘆 × 平坦高揚
インナー → D問いかけ × D救済 × 共鳴型
```

#### アニメ適合度
```
★5（最適）：表情クローズアップ、光の演出、色彩変化、環境の変化、時間の圧縮、メタファー具現化、空間歪曲、トランジション演出
★4（良好）：手元表現、物の対比、シンボル反復
★3（普通）：身体の変化
```

#### 業種別ライブラリの構造
各業種ごとに以下の要素を定義：
- あるある課題
- 専門用語
- 視覚的シンボル
- ターゲットの不安
- 理想の状態
- 数値指標

## 現在のシステム構造との関係

### ファイル構成
```
animePvSettings.js
├── PV_STYLE_PATTERNS（10種類）← スタイル（画風）
├── PV_STORY_PATTERNS（現在8種類）← ストーリーパターン ★今ここを改善中
└── その他のオプション（時間帯、カメラワーク等）

animePvScriptPrompt.js
├── pv_showScriptPromptDialog() ← ダイアログ表示
├── buildScriptPrompt() ← プロンプト生成 ★ここにプレースホルダーが入る
└── pv_parseAndSaveScript() ← 台本パース・保存

animePvSheetManager.js
├── PV_DROPDOWN_OPTIONS ← 選択肢（目的、用途、ターゲット等）
└── ヒアリングシート作成・管理
```

### プレースホルダーの構造（現在）
```javascript
story.name        // ストーリーパターン名
story.description // 説明
story.guidance    // ガイダンス
story.emotionFlow // 感情の流れ
story.sceneStructure // シーン構成の目安
```

### 改善後のイメージ
```javascript
story.name        // パターン名（例：V字回復型）
story.description // 用途の説明（例：「苦しみからの脱出」を描く）
story.emotionFlow // 感情カーブの数値パターン
story.structure   // 構造ルール（谷・ピーク・終わりの位置）
```

## 議論の経緯（どこでズレて、どう修正したか）

### 最初のアプローチ
「B共感×A逆転×V字回復」という組み合わせでストーリーパターンを定義しようとした

### ズレた点
1. 「B共感」「A逆転」は抽象的なラベルであり、具体的な指示ではなかった
2. ストーリーを作ること（マクロ）と、シーンを作成すること（ミクロ）を混同していた
3. 映像表現手法をストーリーパターンに入れようとしていた

### 修正の気づき
- 「B共感×A逆転×V字回復ってなに？具体的になに？」という問いで気づいた
- 感情カーブの数値パターンがあれば、各シーンの感情値は決まる
- オープニング手法・ピーク手法・映像表現は「シーン作成」の話であり、別軸

### 本質の整理
```
ストーリーパターン = 感情カーブ + 構造ルール のプリセット

シーン作成要素（別軸）:
- オープニング手法
- ピーク手法
- 表現手法
- 静止画/動画
```

### まだ検討が必要なこと
- シーン作成要素をどう扱うか
- 全体のプロンプト構造への統合方法
- 静止画/動画の使い分け
