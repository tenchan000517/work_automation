# アニメPV制作 - GASヒアリング自動化マニュアル v2.0

**所要時間**: 30分（初回）/ 15分（2回目以降）
**難易度**: ★★☆☆☆
**前提**: スプレッドシート基本操作

---

## このモジュールで学ぶこと

- ヒアリングシートの構造と使い方
- 文字起こしからのAI自動抽出
- 台本生成・パース・編集の流れ
- 各種プロンプトの自動生成

---

## システム概要

```
【Phase 1: 基本情報入力】
新規シート作成 → 企業名・業種・目的・ターゲット・トンマナを入力
    ↓
【Phase 2: 文字起こし → AI抽出】
「文字起こしを整理」でプロンプト生成 → AIに投入 → 結果を「AI出力を転記」
    ↓
【Phase 3: 台本生成】
「台本生成プロンプト」でストーリー・スタイル選択 → AIに投入
    ↓
【Phase 4: 台本パース・編集】
「台本パース・保存」でJSON展開 → キャラクター・シーン・エンディング編集
    ↓
【Phase 5: プロンプト生成】
├── キャラクターシートプロンプト
├── 開始フレームプロンプト
├── 動画プロンプト（Kling AI / VIDU）
├── SUNO BGMプロンプト
├── SUNO 歌詞付き楽曲プロンプト
└── ナレーションテキスト
```

## GASファイル構成

```
docs/gas/anime-pv/
├── animePvMain.js           # メニュー、初期化、ユーティリティ
├── animePvSettings.js       # 設定管理、スタイル/ストーリーパターン
├── animePvCommonStyles.js   # 共通UIスタイル
├── animePvSheetManager.js   # シート作成・管理
├── animePvFolderManager.js  # フォルダ作成・管理

├── animePvScriptPrompt.js   # 台本生成プロンプト・パース
├── animePvCharacterScene.js # キャラクター・シーン・エンディング編集
```

### スプレッドシートへのデプロイ方法

1. Google Driveで新規スプレッドシートを作成
2. 「拡張機能 > Apps Script」を開く
3. 上記の各ファイルの内容をコピー＆ペースト
4. 保存してスプレッドシートをリロード
5. 「📹 アニメPV制作」メニューが表示されることを確認

## Phase 1: 基本情報入力

### 新規シート作成

1. 「1️⃣ヒアリング > 🆕新規ヒアリングシート作成」を実行
2. ダイアログで以下を入力：

| 項目 | 必須 | 説明 |
|------|------|------|
| 企業名 | ✅ | シート名になります |
| 業種 | ✅ | ドロップダウンから選択または「その他」でカスタム入力 |
| 目的 | - | 新卒採用PV、中途採用PVなど |
| ターゲット | - | 新卒学生（理工系）など |
| トンマナ | - | 知的・誠実、情熱的・熱いなど |

3. 「作成」をクリックすると新しいシートが作成される

### ドロップダウン選択肢

**業種**
- 製造業（機械・金属）/ 製造業（食品・医薬品）/ 製造業（精密機器）
- 建設・土木 / IT・ソフトウェア / 物流・運輸
- 小売・サービス / 医療・福祉 / 教育 / 金融・保険 / その他

**目的**
- 新卒採用PV / 中途採用PV / 会社紹介PV
- サービス紹介PV / 展示会・イベント用 / その他

**ターゲット**
- 新卒学生（理工系）/ 新卒学生（文系）/ 新卒学生（全般）
- 中途転職者 / 顧客・取引先 / 社内向け / 一般消費者 / その他

**トンマナ**
- 知的・誠実 / 情熱的・熱い / 明るい・ポップ
- 落ち着いた・上品 / クール・スタイリッシュ / 温かみ・親しみやすい / その他

### シート構造

| Part | 内容 | 入力者 |
|------|------|--------|
| Part① 基本情報 | 企業情報、PVコンセプト | ダイアログ/営業 |
| Part② AI抽出データ | 文字起こし、コアメッセージ等 | GAS（AI転記） |
| Part③ キャラクター設定 | 2キャラクターの詳細 | GAS（台本パース） |
| Part④ シーン構成 | 12シーン + エンディング | GAS（台本パース） |
| Part⑤ 音声プロンプト | 各種プロンプト | GAS |
| Part⑥ 処理データ | フォルダURL、台本JSON等 | GAS |

## Phase 2: 文字起こし → AI抽出

### Step 1: 文字起こしを整理

1. 「1️⃣ヒアリング > 📝文字起こしを整理」を実行
2. ダイアログにヒアリングの文字起こしテキストを貼り付け
3. 「プロンプト生成」をクリック
4. 生成されたプロンプトを「コピー」

### Step 2: AIに投入

1. Claude または ChatGPT にプロンプトを貼り付け
2. AIがJSON形式で抽出データを出力

### Step 3: AI出力を転記

1. 「1️⃣ヒアリング > 📥AI出力を転記」を実行
2. AIの出力（JSON）を貼り付け
3. 「転記」をクリック
4. Part②に以下が自動展開される：
   - 文字起こし原文
   - コアメッセージ
   - ストーリーアイデア
   - 安全装備
   - NG要素
   - 舞台・世界観
   - 音声設定

## Phase 3: 台本生成

### ストーリーパターンの選択

1. 「2️⃣台本生成 > 📝台本生成プロンプト」を実行
2. ダイアログで**ストーリーパターン**と**スタイル**を選択

#### ストーリーパターン

| パターン | 説明 | 適した業種 |
|---------|------|-----------|
| 成長物語 | 迷い→決意→成長→達成 | 新卒採用、若手向け |
| チームワーク | 個人→仲間→協力→達成 | 製造業、建設業 |
| 挑戦物語 | 限界→覚悟→突破→新境地 | 技術職、研究開発 |
| 日常の発見 | 平凡→気づき→価値の発見 | サービス業、インフラ |
| 変革・イノベーション | 課題→アイデア→実現 | IT、テック企業 |
| 匠の技 | 伝統→修行→継承→発展 | 職人、伝統産業 |

#### アニメスタイル

| スタイル | 特徴 |
|---------|------|
| 新海誠風 | 繊細な光、美しい背景、感情的 |
| デフォルメ | かわいい、親しみやすい |
| エヴァンゲリオン風 | シャープ、緊張感 |
| 鳥山明風 | 明るい、躍動感 |
| ジブリ風 | 柔らかい色彩、温かみ |
| サイバーパンク風 | ネオン、近未来 |
| 水彩画風 | 淡い色、芸術的 |
| 90年代アニメ風 | レトロ、ノスタルジック |
| ピクサー/3D風 | 立体的、親しみやすい |
| 実写風 | リアル、プロフェッショナル |

3. 「プロンプト生成」→「コピー」してClaude/ChatGPTに投入

### 台本生成のポイント

- プロンプトにはPart①②の情報が自動で含まれる
- 12シーン + エンディングの構成で出力される
- キャラクター2名（主人公＋先輩/メンター）の設定が含まれる

## Phase 4: 台本パース・編集

### 台本パース・保存

1. 「2️⃣台本生成 > 📥台本パース・保存」を実行
2. AIが生成した台本JSON（```json...```を含んでもOK）を貼り付け
3. 「パース＆プレビュー」をクリック
4. プレビューを確認して「シートに保存」

#### 自動展開される項目

**Part③ キャラクター設定（2名）**
- 名前、性別・年齢
- 髪型・髪色、目の特徴、体格
- 過去編服装、現在編服装

**Part④ シーン構成（12シーン + エンディング）**
- シーン名、時間帯（過去/現在）
- 場所、登場キャラ
- 演出・動き、ムード
- ナレーション

**エンディング**
- タイプ（オブジェクト→ロゴ変形/ロゴアニメーション）
- 変形元オブジェクト、アニメーション
- 最終テキスト

### キャラクター編集

1. 「3️⃣編集 > 👤キャラクター編集」を実行
2. キャラクター1/2をタブで切り替え
3. 各項目を編集
4. 「保存」でシートに反映

### シーン編集

1. 「3️⃣編集 > 🎬シーン編集」を実行
2. 編集するシーンを選択
3. 各項目を編集
4. **オプション追加**で以下を設定可能：
   - カメラワーク
   - キャラクターの動き
5. 「保存」でシートに反映

### エンディング編集

1. 「3️⃣編集 > 🏁エンディング編集」を実行
2. タイプ、変形元、アニメーション、最終テキストを編集
3. 「保存」でシートに反映

## Phase 5: プロンプト生成

### キャラクターシートプロンプト

1. 「4️⃣画像プロンプト > 🎨キャラクターシートプロンプト生成」を実行
2. スタイルを選択
3. キャラクター1/2のタブを切り替え
4. 「コピー」または「保存」

### 開始フレームプロンプト

1. 「4️⃣画像プロンプト > 🖼️開始フレームプロンプト生成」を実行
2. スタイルとシーンを選択
3. 「全シーン一括生成」で一括保存も可能

### 動画プロンプト

1. 「5️⃣動画プロンプト > 🎬Kling AI / VIDU」を実行
2. シーンを選択
3. カメラワーク・キャラクターの動きを選択
4. 「全シーン一括生成」で一括保存も可能

### 音声プロンプト

**SUNO BGM**
1. 「6️⃣音声プロンプト > 🎵SUNO冒頭BGMプロンプト」を実行
2. BGMスタイルを選択（ピアノソロ、オーケストラ等）

**SUNO歌詞付き楽曲**
1. 「6️⃣音声プロンプト > 🎤SUNO歌詞付き楽曲プロンプト」を実行
2. ボーカルスタイルを選択

**歌詞生成**
1. 「6️⃣音声プロンプト > ✏️歌詞生成プロンプト」を実行
2. プロンプトをコピーしてAIに投入
3. 「📥歌詞を貼り付け・保存」で保存

## トラブルシューティング

### メニューが表示されない

1. スプレッドシートをリロード
2. Apps Scriptで「onOpen」関数を手動実行

### 文字起こし転記が失敗する

1. AIの出力がJSON形式になっているか確認
2. ```json ... ``` で囲まれていてもパース可能

### 台本パースに失敗する

1. AIの出力がJSON形式になっているか確認
2. 12シーン + エンディング構造になっているか確認
3. キャラクターが2名設定されているか確認

### フォルダ作成に失敗する

1. 「⚙️設定 > 📁親フォルダを設定」でIDを再設定
2. Google DriveのフォルダIDが正しいか確認

### 編集内容が保存されない

1. 「保存」ボタンをクリックしたか確認
2. ステータスメッセージを確認
