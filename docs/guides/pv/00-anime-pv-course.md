## セクション3: キャラクター設計

| 項目 | 決めること |

### Step 2: キャラクターシートを作成

Gemini 3 Pro Imageでキャラクターシートを生成します。

**プロンプトテンプレート:**

```

[服装の説明].

Show the character from multiple angles: front view, side profile, and three-quarter view.
Include both full body poses and upper body close-ups.

Use a clean white background. The art style should have detailed shading, soft lighting,
and the atmospheric quality seen in films like "Your Name" or "Weathering with You".
```

### 作成するシート

1. 過去編キャラクターシート
2. 現在編キャラクターシート
3. 表情シート（6表情）
4. サブキャラクターシート（必要に応じて）

## セクション4: シーン構成・タイムライン

### Step 1: 基本構成を決める（45秒の場合）

| 時間 | フェーズ | 内容 | 音楽 |
|------|---------|------|------|
| 0-10秒 | 導入（Past） | 過去の主人公、迷い | ピアノソロ + ナレーション |
| 10-20秒 | 転換（Change） | 決意、現場への一歩 | ビルドアップ |
| 20-40秒 | サビ（Action） | 仕事の魅力、活躍 | 歌詞付き楽曲 |
| 40-45秒 | 結び（Future） | 希望、ロゴ | フェードアウト |

### Step 2: シーンリストを作成

各5秒で9シーン（+追加シーン）を設計します。

**シーンリストテンプレート:**

| No. | シーン名 | 時間 | 主人公 | 場所 | 演出 |
|-----|---------|------|--------|------|------|
| 1 | 日常と迷い | 0-5秒 | 過去 | カフェ/学校 | 窓を見つめる |
| 2 | 目覚め | 5-10秒 | 過去 | 同上 | 何かに気づく |
| 3 | 現場への一歩 | 10-15秒 | 現在 | 工場入口 | 入っていく |
| ... | ... | ... | ... | ... | ... |

### Step 3: 感情の流れを設計

```
迷い → 発見 → 決意 → 行動 → 挑戦 → 成長 → 達成 → 希望
```

シーンごとに主人公の感情状態を明確にします。

## セクション5: 画像生成（Gemini 3 Pro Image）

### Step 1: プロンプトの基本構造を理解する

```
Create an anime scene in the style of Makoto Shinkai films.

[シーンの説明 - 誰が、どこで、何をしているか]

[照明・雰囲気の説明]

[感情・ムードの説明]

Cinematic composition, 16:9 aspect ratio.
```

### Step 2: 重要なキーワードを覚える

**画風:**
- `Makoto Shinkai style` - 新海誠風
- `anime scene` - アニメシーン
- `high quality` - 高品質

**照明:**
- `golden hour` - 夕暮れ時
- `morning light` - 朝の光
- `dramatic lighting` - ドラマチックな照明
- `lens flare` - レンズフレア

**構図:**
- `close-up` - クローズアップ
- `wide shot` - ワイドショット
- `low angle shot` - ローアングル
- `shot from behind` - 後ろからのショット

**雰囲気:**
- `emotional atmosphere` - 感情的な雰囲気
- `hopeful` - 希望に満ちた
- `determined` - 決意した
- `cinematic composition` - 映画的構図

### Step 3: 各シーンで作成するもの

| 種類 | 説明 |
|------|------|
| 開始フレーム | 動画の最初の画像 |
| 終了フレーム | 動画の最後の画像 |

※動画AIが開始→終了を補間して動画を生成します

### Step 4: キャラクター一貫性のコツ

1. **キャラクターシートを先に作成**
2. **参照画像として毎回添付**
3. **特徴を毎回プロンプトに含める**（髪型、服装など）

### チェックポイント

- [ ] プロンプトの基本構造を理解した
- [ ] 重要なキーワードをメモした
- [ ] 各シーンの開始・終了フレームを生成した

## セクション6: 動画生成（Kling AI）

### Step 1: Image to Videoの基本

開始フレーム画像をアップロードし、動きを指示します。

**プロンプト構造:**

```
[主体] + [動き] + [カメラワーク] + [雰囲気]
```

### Step 2: 動きの指示キーワード

**人物の動き:**
- `slowly raises her head` - ゆっくり頭を上げる
- `turns toward the camera` - カメラの方を向く
- `walks forward` - 前に歩く
- `smiles gently` - 優しく微笑む

**カメラワーク:**
- `static camera` - 固定カメラ
- `slow pan upward` - ゆっくり上にパン
- `tracking shot` - 追従ショット
- `zoom out` - ズームアウト
- `stable camera movement` - 安定したカメラ動き

**雰囲気:**
- `hopeful atmosphere` - 希望に満ちた雰囲気
- `emotional moment` - 感情的な瞬間
- `dynamic energy` - ダイナミックなエネルギー

### Step 3: 設定

| 項目 | 推奨値 |
|------|--------|
| Duration | 5 seconds |
| Mode | Standard / Professional |
| Aspect Ratio | 16:9 |

## セクション7: 音楽生成（SUNO）

### Step 1: BGM（インストゥルメンタル）を生成

ナレーションが入る部分はボーカルなしで作成します。

**プロンプト例:**

```
Cinematic instrumental, emotional piano solo, ambient atmosphere,
slow tempo 60-70 BPM, melancholic yet hopeful, soft strings gradually entering,
film score style, no vocals, Japanese anime movie soundtrack feel
```

**重要なキーワード:**
- `instrumental` - 楽器のみ
- `no vocals` - ボーカルなし
- `cinematic` - 映画的
- `building` - 盛り上がっていく

### Step 2: 歌詞付き楽曲を生成

**スタイルプロンプト例:**

```
Modern J-pop, crystal clear high female vocals, pure and bright tone
with emotional depth, energetic yet delicate delivery, tempo 130-140 BPM,
synth-driven with piano accents, anime theme song feel, Japanese lyrics
```

**ボーカルスタイルの表現:**

| イメージ | プロンプト表現 |
|---------|---------------|
| 透明感のある高音 | crystal clear high vocals |
| 力強い男性ボーカル | powerful male vocals |
| グループハーモニー | group harmonies |
| 感情豊か | emotionally expressive |

### Step 3: 歌詞を書く

**メタタグを使う:**

```
[Chorus - Full Band, Powerful]
歌詞をここに

[Verse - Softer, Solo]
歌詞をここに

[Bridge - Emotional]
歌詞をここに

[Outro - Fade Out]
歌詞をここに
```

### チェックポイント

- [ ] BGM（インスト）を生成した

- [ ] 音楽のタイミングを確認した

## トラブルシューティング

### 画像生成

| 問題 | 解決策 |
|------|--------|
| キャラが毎回違う | キャラクターシートを参照画像として添付 |
| 背景が単調 | 照明・時間帯の指定を追加 |
| 構図が悪い | `cinematic composition`を追加 |

### 動画生成

| 問題 | 解決策 |
|------|--------|
| 動きが速すぎる | `slowly`, `gently`を追加 |
| 顔が崩れる | 顔の動きを最小限に |
| 背景が変わる | `maintain background`を追加 |

### 音楽生成

| 問題 | 解決策 |
|------|--------|
| ボーカルが入る | `instrumental`, `no vocals`を追加 |
| テンポが合わない | BPMを明示的に指定 |
| 雰囲気が違う | ジャンル・ムードを詳しく記述 |

## まとめ

このモジュールでは、AI生成ツールを活用したアニメPV制作の全工程を学びました。

### 制作の流れ

```
企画 → キャラ設計 → シーン構成 → 画像生成 → 動画生成 → 音楽生成 → 編集 → 完成
```

### 重要なポイント

1. **コアメッセージを明確に** - 1つのメッセージに絞る
2. **キャラクターシートを先に** - 一貫性の基準を作る
3. **感情の流れを設計** - シーンごとの感情を明確に
4. **プロンプトは具体的に** - 曖昧な表現を避ける

### 次のステップ

1. まずはサンプルプロジェクトを参考に1本作ってみる
2. 自社の業種に合わせてカスタマイズ
3. クライアント向けにテンプレート化

## よくある質問

### Q: 1本作るのにどれくらいかかりますか？

慣れてくると、画像生成〜動画生成で2-3時間、編集で1-2時間程度です。

### Q: 著作権は大丈夫ですか？

各AIサービスの利用規約を確認してください。商用利用可能なプランを選ぶことを推奨します。

### Q: キャラクターが毎回違ってしまいます

キャラクターシートを作成し、毎回参照画像として添付してください。また、プロンプトに特徴（髪型、服装など）を必ず含めてください。

### Q: 音楽と映像のタイミングが合いません

サビの開始タイミングを先に決め、そこに合わせてシーンを調整してください。15秒目にサビ開始がおすすめです。
