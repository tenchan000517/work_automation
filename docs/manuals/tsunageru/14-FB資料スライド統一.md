# FB資料スライドレイアウト統一マニュアル

## 概要

Google スライドで作成するFB資料において、1ページ目を基準として2〜20ページ目の要素（テーブル、グラフ、画像等）の位置・サイズを統一する手順を解説する。

### 対象

- 複数ページで同じ構成のスライド（FB資料など）
- スプレッドシートとリンクしたグラフを含むスライド

### 統一される項目

| 要素タイプ | 位置（X, Y） | サイズ（幅 x 高さ） | 行高さ・列幅 |
|-----------|-------------|-------------------|-------------|
| SHEETS_CHART | ○ | ○ | - |
| TABLE | ○ | - | ○ |
| IMAGE | ○ | ○ | - |
| SHAPE | ○ | ○ | - |

### 変更されないもの

- テーブル内のテキスト
- リンク（スプレッドシートリンク含む）
- 書式（フォント、色など）
- セル内の画像

---

## 事前準備

### 1. Slides API の有効化

1. Google スライドを開く
2. **拡張機能** → **Apps Script** をクリック
3. 左メニューの **サービス** 横の **+** をクリック
4. **Slides API** を選択
5. **追加** をクリック

![Slides API追加](../../images/slides-api-setup.png)

### 2. スクリプトの準備

1. Apps Script エディタで **+** → **スクリプト** をクリック
2. ファイル名を `slideLayoutManager` に変更
3. 以下のGASスクリプトを貼り付け

**GASスクリプト保存場所**: `docs/gas/tsunageru/slideLayoutManager.js`

## 実行手順

### Step 1: 構造分析（任意）

1ページ目の構造を確認したい場合に実行。

1. 関数セレクタで **`analyzeFirstSlide`** を選択
2. **▶ 実行** をクリック
3. **Ctrl + Enter** でログを確認

```
=== 1ページ目の要素構造 ===
要素数: 6

--- 要素 0 [SHEETS_CHART] ---
位置: X=364.9, Y=202.5
サイズ: W=303.6, H=188.2
スプレッドシートリンクあり

--- 要素 1 [SHEETS_CHART] ---
位置: X=364.9, Y=9.4
サイズ: W=283.2, H=175.5
...
```

### Step 2: 位置統一

1. 関数セレクタで **`alignToFirstSlide`** を選択
2. **▶ 実行** をクリック
3. 完了ログを確認

```
基準レイアウト（Y座標順）:
  SHEETS_CHART: 2個 [Y=9, Y=203]
  TABLE: 2個 [Y=17, Y=203]
...

```

### Step 3: テーブルサイズ統一

1. 関数セレクタで **`alignTableSizesAdvanced`** を選択
2. **▶ 実行** をクリック
3. 完了ログを確認

```

  行数: 10, 列数: 8

  行数: 9, 列数: 8
```

## トラブルシューティング

### エラー: 「Slides is not defined」

**原因**: Slides API が有効化されていない

**解決方法**:
1. サービス → + → Slides API → 追加

### エラー: 「サイズ不一致なし」なのにサイズが違う

**原因**: TABLEはgetWidth()/getHeight()でサイズ取得できないため検出されない

**解決方法**:
1. `alignTableSizesAdvanced` を実行

### 要素が正しくマッチングされない

**原因**: ページごとに要素の作成順序が異なる

**解決方法**:
スクリプトはY座標でソートしてマッチングするため、通常は自動で対応される。それでもズレる場合は `compareWithFirstSlide(2)` でデバッグ。

## 設定変更

### 対象ページ範囲の変更

`slideLayoutManager.js` の CONFIG を編集:

```javascript
var CONFIG = {
  START_PAGE: 2,    // 開始ページ（1始まり）
  END_PAGE: 20,     // 終了ページ（1始まり）
  TARGET_TYPES: ['SHEETS_CHART', 'TABLE', 'IMAGE', 'SHAPE']
};
```

### 特定の要素タイプのみ対象にする

```javascript
TARGET_TYPES: ['SHEETS_CHART']  // グラフのみ
TARGET_TYPES: ['TABLE']         // テーブルのみ
```

## 技術詳細

### 位置統一の仕組み

1. 1ページ目の全要素を取得
2. 要素タイプ別にグループ化
3. 各グループをY座標でソート（上から順）
4. 2〜20ページでも同様にソート
5. 同じタイプ・同じ順番の要素をマッチング
6. 位置（setLeft, setTop）とサイズ（setWidth, setHeight）を適用

### テーブルサイズ統一の仕組み

GASの標準APIではテーブルの行高さ・列幅を設定できないため、**Advanced Slides Service**（REST API）を使用。

```javascript
// 行高さ設定
{
  updateTableRowProperties: {
    objectId: tableId,
    rowIndices: [0],
    tableRowProperties: {
      minRowHeight: { magnitude: 285600, unit: 'EMU' }
    },
    fields: 'minRowHeight'
  }
}

// 列幅設定
{
  updateTableColumnProperties: {
    objectId: tableId,
    columnIndices: [0],
    tableColumnProperties: {
      columnWidth: { magnitude: 747550, unit: 'EMU' }
    },
    fields: 'columnWidth'
  }
}
```

### 単位について

- **PT（ポイント）**: 1 PT = 12,700 EMU
- **EMU（English Metric Units）**: Slides API の内部単位
