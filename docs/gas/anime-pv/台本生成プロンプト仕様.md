# 台本生成プロンプト仕様

## 概要

このドキュメントは台本生成プロンプトの構造と仕様を記録したものです。

---

## 設計思想

### 役割分担

| 役割 | 担当 | 内容 |
|------|------|------|
| **システム設計者** | GAS開発者 | 出力形式（JSON）の要件を正確に伝える |
| **クリエイター** | AI | ストーリーの内容を考える |

### 整理された構造

| 項目 | 内容 |
|------|------|
| **目的** | ブランディング / 応募・受注獲得 / 理解促進 / インナーブランディング |
| **用途** | 新卒採用PV、高卒採用PV、中途採用PV、会社紹介PV、サービス紹介PV、展示会・イベント用 |
| **ターゲット** | 大卒学生、高卒学生、中途転職者、顧客・取引先、新入社員、既存社員、一般消費者 |

## ドロップダウン選択

### 目的（4種類）

| 選択肢 | 説明 |
|--------|------|
| ブランディング（認知・イメージ向上） | 企業の認知度やイメージを高める |
| 応募・受注獲得（行動を促す） | 応募や問い合わせなどの行動を促す |
| 理解促進（何をしている会社か伝える） | 事業内容や強みを分かりやすく伝える |
| インナーブランディング（社員の帰属意識向上） | 社員の誇りや帰属意識を高める |

### 用途（6種類）

| 選択肢 | 主なターゲット |
|--------|--------------|
| 新卒採用PV | 大卒学生 |
| 高卒採用PV | 高卒学生 |
| 中途採用PV | 中途転職者 |
| 会社紹介PV | 顧客・取引先・全般 |
| サービス紹介PV | 顧客・一般消費者 |
| 展示会・イベント用 | 顧客・取引先 |

### ターゲット（7種類）

| 選択肢 | 特徴 |
|--------|------|
| 大卒学生 | 就活中の大学生・大学院生 |
| 高卒学生 | 就活中の高校生 |
| 中途転職者 | 転職を検討している社会人 |
| 顧客・取引先 | B2B顧客、取引先企業 |
| 新入社員 | 入社直後の社員 |
| 既存社員 | 在籍中の社員 |
| 一般消費者 | B2C顧客、一般の消費者 |

### ストーリーパターン（8種類）

| ID | 名前 | 説明 | 推奨用途 |
|----|------|------|----------|
| growth | 成長物語（過去→現在） | 学生時代から成長して今の姿へ | 新卒採用（大卒・高卒） |
| presentday | 現在進行形（今の姿） | 過去の回想なし、今の1日を描く | 中途採用 |
| teamwork | チームワーク | 仲間と協力して達成 | 全採用形態 |
| challenge | 挑戦物語 | 困難に立ち向かい突破 | 全採用形態 |
| everyday | 日常の価値 | 当たり前の中の価値を発見 | サービス業・インフラ |
| transformation | 変革・イノベーション | 問題意識から新しい価値を創造 | IT・テック・研究開発 |
| craft | 匠の技（継承） | 技術を学び継承する | 製造業・職人・伝統産業 |
| company_intro | 会社紹介（事業説明） | 事業内容・強み・ビジョンを紹介 | 会社紹介・展示会 |

## 出力JSON仕様（システム要件）

```typescript
interface ScriptOutput {
  characters: Character[];
  scenes: Scene[];
  ending: Ending;
}

interface Character {
  name: string;           // 必須：日本人名
  gender: string;         // 必須：男性 | 女性
  currentAge: string;     // 必須：現在の年齢
  pastAge: string;        // 任意：過去編がある場合のみ
  hair: string;           // 必須：英語で髪型・髪色
  eyes: string;           // 必須：英語で目の特徴
  build: string;          // 必須：英語で体格
  pastOutfit: string;     // 任意：過去編がある場合のみ
  currentOutfit: string;  // 必須：現在の服装（安全装備含む）
}

interface Scene {
  name: string;           // 必須：シーン名
  phase: string;          // 必須：過去 | 転換点 | 現在 | 未来
  location: string;       // 必須：場所
  characters: string;     // 必須：登場キャラクター
  action: string;         // 必須：動作・演出
  mood: string;           // 必須：雰囲気
  narration: string;      // 任意：ナレーション（4-6シーンに配置）
  videoPrompt: string;    // 必須：英語で動画生成用プロンプト
}

interface Ending {
  type: string;           // 必須："object_to_logo" | "logo_animation"
  sourceObject: string;   // object_to_logoの場合必須
  animationType: string;  // logo_animationの場合必須
  finalText: string;      // 必須：最終テキスト
  videoPrompt: string;    // 必須：英語でエンディング用プロンプト
}
```

## 改善履歴

### v2.0（現在）

**改善点:**
1. **目的と用途を分離**: 「目的」（何を達成したいか）と「用途」（どんなPVを作るか）を明確に分けた
2. **固定値の削除**: 年齢（17-22歳など）の固定指定を削除し、AIが用途・ターゲットに応じて判断
3. **ストーリーパターンの拡充**: 6種類→8種類に増加、各パターンに具体的なガイダンスを追加
4. **専門家の知見を反映**: CMディレクター、広告クリエイティブディレクター、採用マーケティング、映像脚本家の視点を各パターンに追加
5. **シーン構成の目安を追加**: 各パターンに12シーンの配分目安を設定
6. **システム要件とクリエイティブの分離**: 出力形式（JSON）はシステム要件、内容はAIに委ねる設計
