# インナーブランディング・教育系に特化したスタイル分析

採用PV（外向け）と**インナーブランディング・教育系（内向け）**では目的が全く異なります。既存の5スタイルに加えて、**社員の動機付け・モチベーション向上・企業文化の浸透**に特化したスタイルをリサーチします。

---

## インナー向けと採用向けの本質的違い

| 要素 | 採用PV（外向け） | インナー・教育系（内向け） |
|------|-----------------|------------------------|
| **目的** | 魅力を伝える・応募させる | 行動変容・意識改革・モチベーション |
| **ターゲット** | 外部の候補者 | 既存社員・新入社員 |
| **トーン** | 理想を見せる | リアル・共感・本音 |
| **メッセージ** | 「来て欲しい」 | 「あなたは既にここにいる」 |
| **感情設計** | 憧れ・希望 | 誇り・責任感・一体感 |
| **尺** | 30秒〜2分（短め） | 3分〜15分（長め可） |
| **視聴環境** | SNS・採用サイト | 研修・全社会議・イントラ |

---

## 追加推奨スタイル6選

- **スタイル6: TED Talk / プレゼンテーション型**

- **スタイル10: ゲーミフィケーション（教育ゲーム）型**

## スタイル6: TED Talk / プレゼンテーション型

### コンセプト
**「一人の語り手が、ストーリーとデータで心を動かす」**

### 適した用途
- 経営ビジョンの共有
- 新戦略の発表
- 企業文化の説明
- リーダーシップ研修
- 変革の動機付け

### 映像言語の特徴

#### 1. スピーカー中心の構図
```
基本構成：
・スピーカーの立ち姿（1/3画面）
・残り2/3に視覚資料
・アイコンタクト（カメラ目線）
・ジェスチャーの効果的使用
```

#### 2. トランジション設計

**導入部（問題提起）:**
```
[黒画面]
  ↓
[スピーカー登場 2秒]
  「皆さんに質問があります」
  ↓
[画面分割 1秒]
  左：スピーカー
  右：問いかけの文字
  ↓
[聴衆の反応カット 1秒]
  ↓
[フルスクリーン データ表示 3秒]
  「実は、私たちの90%が...」
```

**展開部（ストーリー）:**
```
[スピーカーのクローズアップ]
  個人的エピソード語り
  ↓
[イラスト/アニメーション展開 2秒]
  ストーリーの視覚化
  ↓
[再びスピーカー]
  感情を込めて
  ↓
[データ/グラフ表示]
  裏付け
```

**クライマックス（解決策）:**
```
[画面分割×4]
  4つのポイント同時表示
  ↓
[順番に拡大 各2秒]
  スピーカーが説明
  ↓
[全画面 重要メッセージ 3秒]
  「だから、私たちは...」
```

**結論（行動喚起）:**
```
[スピーカー フルスクリーン]
  力強いメッセージ
  ↓
[画面が明るくなる 2秒]
  ↓
[行動喚起テキスト]
  「今日から始めよう」
  ↓
[拍手・感動のエンディング]
```

### トランジション技法

**A. スライド切替風:**
```
・横スライド（PowerPoint風）
・フェードスルーブラック
・ズームトランジション
・ワイプ（シンプルに）
```

**B. データビジュアライゼーション:**
```
・グラフのアニメーション成長
・数字のカウントアップ
・インフォグラフィックの展開
・タイムライン表示
```

**C. 感情の波に合わせた切替:**
```
静かな語り → ゆっくりディゾルブ（2秒）
興奮の瞬間 → スナップカット（0フレーム）
重要な数字 → ズームイン＋停止（3秒）
```

### カラー設計
```
基本：
・背景：ダークグレー/黒（TEDステージ風）
・テキスト：白/企業カラー
・データ：シンプルな3色まで
・スピーカーにスポットライト

感情別：
・問題提起：暗め・寒色
・解決策：明るい・暖色
・行動喚起：企業ブランドカラー
```

### 音楽・音響
```
・BGM：控えめ・邪魔しない
・スピーカーの声が主役
・重要な瞬間：音楽を止める
・データ表示時：軽いSE（シュッ、ポン）
・クライマックス：音楽盛り上がり
```

## スタイル7: ピクサー（感動ストーリーテリング）型

### コンセプト
**「3幕構造の完璧な物語で、涙と笑いを引き出す」**

### 適した用途
- 企業の歴史・創業ストーリー
- 社員の成長物語
- 失敗からの復活
- チームの絆を描く
- 全社会議のオープニング

### ピクサー「22のストーリーテリングルール」より

#### 映像への応用

**1. 「むかしむかし...」構造:**
```
むかしむかし、___がいました
毎日、___していました
ある日、___が起こりました
そのせいで、___になりました
そのせいで、___になりました
ついに、___しました
それ以来、___になりました
```

**インナー動画への応用例:**
```
むかしむかし、迷っていた新入社員がいました
毎日、自信を失っていました
ある日、先輩が声をかけてくれました
そのおかげで、チャレンジする勇気が出ました
そのおかげで、プロジェクトが成功しました
ついに、チームのリーダーになりました
それ以来、後輩を育てる立場になりました
```

### トランジション設計

#### 第1幕（Setup - 日常世界）
```
[柔らかいフェードイン 3秒]
  ↓
[主人公の日常 長回し 5秒]
  ゆったりとした動き
  ↓
[ディゾルブ 2秒]
  時間経過・日常の反復
  ↓
[小さな違和感の挿入 1秒]
  何かが変わる予兆
```

**ピクサー的カメラワーク:**
- 温かみのある光
- 柔らかいフォーカス
- ゆっくりしたパン・チルト
- キャラクターの表情重視

#### 第2幕（Confrontation - 困難と成長）
```
[転換点：ハードカット 0フレーム]
  日常が壊れる瞬間
  ↓
[モンタージュ（成長の過程）]
  ・失敗 [1秒] → ディゾルブ
  ・再挑戦 [1秒] → ディゾルブ
  ・小さな成功 [1秒] → ディゾルブ
  ・仲間の支え [1秒]
  ↓
[最も暗い瞬間 長回し 5秒]
  諦めかける
  ↓
[希望の光（比喩的に）2秒]
  フェードイン
```

**感情カーブの視覚化:**
```
楽観 → 挫折 → 絶望 → 小さな希望 → 再挑戦 → 勝利

各段階でトランジション速度を変える：
楽観：ゆっくり（2秒ディゾルブ）
挫折：速く（0.5秒ハードカット）
絶望：非常にゆっくり（3秒ディゾルブ）
希望：徐々に速く（1.5秒→1秒→0.5秒）
勝利：爆発的に速く（0.3秒連続カット）
```

#### 第3幕（Resolution - 解決と成長後）
```
[クライマックス]
  ・高速カッティング（0.3秒×10）
  ・音楽の盛り上がりと完全同期
  ↓
[成功の瞬間 スローモーション 3秒]
  時間を引き延ばす
  ↓
[ゆっくりとした余韻 5秒]
  仲間との抱擁・笑顔
  ↓
[フェードトゥホワイト 3秒]
  明るい未来へ
  ↓
[エピローグ（変化後の日常）]
  最初のシーンと対比
```

### ピクサー独特のトランジション

**A. 「マッチカット」（視覚的連続性）:**
```
例：「リメンバー・ミー」
少年のギター → 祖父のギターへディゾルブ

インナー動画応用：
新入社員の初日 → 5年後の同じ場所
同じ構図・同じカメラアングル
```

**B. 「感情の色彩変化」:**
```
悲しみ：彩度-30、青みがかる
喜び：彩度+20、暖色に
絶望：モノクロに近づく
希望：徐々にカラフルに
```

**C. 「音楽主導のトランジション」:**
```
音楽のフレーズが変わる瞬間 = カット切替
・静かなピアノ → 弦楽器が入る = 希望の兆し
・フルオーケストラ → 突然の静寂 = 危機
```

## スタイル8: Nike / Apple（インスピレーショナル）型

### コンセプト
**「短く、力強く、行動を促す。スローガンが心に残る」**

### 適した用途
- 営業チームの士気向上
- 全社キックオフ
- チャレンジ精神の喚起
- 困難な時期の励まし
- 新プロジェクトの始動

### 映像言語の特徴

#### Nike「Just Do It」スタイル

**1. アスリート（社員）の汗と努力:**
```
[黒画面]
  ↓
[0.5秒：早朝の目覚まし]
  ↓
[0.5秒：走り出す足元]
  ↓
[0.5秒×10：高速モンタージュ]
  ・汗
  ・集中した目
  ・限界への挑戦
  ・仲間との競争
  ・転倒
  ・立ち上がる
  ↓
[3秒：スローモーション 勝利の瞬間]
  ↓
[2秒：ロゴ＋スローガン]
  「JUST DO IT」
```

**トランジション特徴:**
- **超高速カット（0.3-0.5秒）**
- **ハードカット中心**
- **スローモーションの効果的使用**
- **モノクロ⇔カラーの切替**
- **突然の静止画**

#### Apple「Think Different」スタイル

**2. ビジョナリーの肖像:**
```
[静かな音楽]
  ↓
[偉人の写真 静止画 2秒]
  アインシュタイン
  ↓
[ディゾルブ 1秒]
  ↓
[別の偉人 2秒]
  ピカソ
  ↓
[ナレーション]
  「クレイジーな人たちへ」
  ↓
[現代の挑戦者（社員）へ繋ぐ]
  ↓
[メッセージ]
  「Think Different」
```

**トランジション特徴:**
- **ゆっくりとしたディゾルブ（1.5-2秒）**
- **モノクロ基調**
- **ミニマルな構成**
- **余白の美学**
- **ナレーション主導**

### トランジション技法比較

| 要素 | Nike型 | Apple型 |
|------|--------|---------|
| **カット長** | 0.3-0.5秒 | 2-3秒 |
| **トランジション** | ハードカット | ディゾルブ |
| **色彩** | カラフル・原色 | モノクロ・ミニマル |
| **音楽** | 激しい・ビート | 静か・感動的 |
| **メッセージ** | 「やれ」 | 「考えろ」 |

### メッセージの作り方

**Nike型（命令形・短い）:**
```
・「Just Do It」（やれ）
・「限界は、自分が決める」
・「諦めるな」
・「今日が勝負だ」
・「挑戦し続けろ」
```

**Apple型（詩的・余韻）:**
```
・「Think Different」（違った見方を）
・「クレイジーな人たちが、世界を変える」
・「私たちは、未来を創る人たちです」
・「ここには、可能性しかない」
・「君の、次の一歩が世界を変える」
```

## スタイル9: ドキュメンタリー（NHK / BBC）型

### コンセプト
**「事実と感情のバランス。リアルな声が信頼を生む」**

### 適した用途
- 企業の歴史ドキュメント
- プロジェクトの裏側
- 社員インタビュー集
- 社会貢献活動の記録
- 職人技・専門性の紹介

### 映像言語の特徴

#### NHKスタイル（丁寧・教育的）

**1. インタビュー構図:**
```
基本設定：
・被写体は中央やや左/右
・目線はカメラ外（インタビュアー）
・背景は職場・関連する場所
・自然光＋補助光
・マイク見えてOK（リアル感）
```

**2. トランジション設計:**

**導入:**
```
[空撮または風景 5秒]
  企業の所在地・工場など
  ↓
[ナレーション開始]
  「ここは、〇〇県〇〇市...」
  ↓
[ゆっくりズームイン 3秒]
  ↓
[カット 内部へ]
  ↓
[働く人々の姿 3秒]
  ↓
[最初のインタビュー]
```

**展開:**
```
[インタビュー 5秒]
  社員A「私がこの会社に...」
  ↓
[カットアウェイ 3秒]
  語られている内容の映像
  （作業風景・過去の写真）
  ↓
[再びインタビュー 4秒]
  続き
  ↓
[別の角度またはズーム]
  感情の変化を捉える
```

### ドキュメンタリー特有のトランジション

**A. カットアウェイ（Bロール挿入）:**
```
インタビュー → 関連映像 → インタビュー
```

**B. ジャンプカット:**
```
同じ人物・異なるタイミング
時間経過を示す
```

**C. シーケンストランジション:**
```
一連の動作を複数カットで
（例：コーヒーを淹れる工程）
```

**D. タイムラプス:**
```
・1日の流れを数秒に圧縮
・季節の変化
・プロジェクトの進行
→ 時間経過を効果的に表現
```

**E. フェードスルーブラック:**
```
・章立て
・時間の大きな跳躍
・トーンの切替
→ 2-3秒の黒画面を挟む
```

**F. スプリットスクリーン:**
```
・異なる場所の同時刻
・ビフォー・アフター
・複数の視点
→ 画面を分割して同時表示
```

**G. アーカイブ映像の挿入:**
```
・過去の写真/動画
・新聞記事
・歴史的資料
→ セピア調・グレインで差別化
```

## スタイル10: ゲーミフィケーション（教育ゲーム）型

### コンセプト
**「学びをゲーム化。達成感とエンゲージメントを最大化」**

### 適した用途
- 新人研修動画
- コンプライアンス教育
- スキルアップ講座
- 安全教育
- 営業トレーニング

### 映像言語の特徴

#### RPGゲーム風インターフェース

**1. ステータス表示常設:**
```
画面構成：
┌─────────────────────────┐
│ HP: ████████░░ 80/100   │ ← 上部バー
├─────────────────────────┤
│                         │
│   [メイン映像]          │ ← 中央
│                         │
├─────────────────────────┤
│ 経験値: ████░░░░ 400/1000│ ← 下部バー
│ レベル: 5  次: Lv.6     │
└─────────────────────────┘

常に表示：
・現在の進捗
・獲得ポイント
・達成率
・残り時間（チャレンジ系）
```

**2. トランジション設計:**

**レベルアップトランジション:**
```
[通常シーン]
  ↓
[画面が光る 0.3秒]
  ↓
[0.5秒：画面全体にエフェクト]
  キラキラ・星・光の粒子
  ↓
[1秒：「LEVEL UP!」表示]
  フォント：ゲーム風・大きく
  効果音：ピロリロリン
  ↓
[0.5秒：ステータス変化アニメーション]
  数値がカウントアップ
  ↓
[通常シーンに戻る]

使用タイミング：
・章の完了
・重要なスキル習得
・クイズ正解
・マイルストーン到達
```

**スキル習得トランジション:**
```
[説明シーン]
  ↓
[0.3秒：画面右からスライドイン]
  ┌───────────────┐
  │ 新スキル獲得！│
  ├───────────────┤
  │ [アイコン]    │
  │ 「傾聴力」    │
  │ Lv.1 習得     │
  └───────────────┘
  ↓
[1秒：表示キープ]
  効果音：シャキーン！
  ↓
[スライドアウト]
```

**ミッション開始トランジション:**
```
[前のシーン終了]
  ↓
[1秒：暗転]
  ↓
[テキスト表示]
  「MISSION 03」
  「難易度：★★☆☆☆」
  「目標：顧客対応をマスターせよ」
  ↓
[2秒：ミッション内容]
  ・条件1
  ・条件2
  ・報酬：経験値500
  ↓
[0.5秒：「START」ボタン風]
  ↓
[ミッションシーン開始]
```

**クイズ/選択肢トランジション:**
```
[問題シーン]
  ↓
[画面下部からスライドアップ]
  ┌───────────────────┐
  │ Q: この場合の正しい対応は？│
  ├───────────────────┤
  │ A. ___________      │
  │ B. ___________      │
  │ C. ___________      │
  └───────────────────┘
  ↓
[カウントダウン表示 10秒]
  ↓
[選択（自動またはインタラクティブ）]
  ↓
[正解の場合]
  ・画面が緑に光る 0.3秒
  ・「CORRECT! +100 EXP」
  ・効果音：ピンポン
  ↓
[不正解の場合]
  ・画面が赤に光る 0.3秒
  ・「INCORRECT... 再挑戦」
  ・効果音：ブー
  ・解説表示
```

### ゲーミフィケーション要素の統合

#### 1. ポイント/経験値システム
```
画面常設表示：
右上：現在の経験値バー
左上：現在のレベル

獲得タイミング：
・動画視聴完了：+50 EXP
・クイズ正解：+100 EXP
・実践課題クリア：+300 EXP
・ボーナスミッション：+500 EXP

視覚表現：
・数字が飛び出すアニメーション
・バーがニュル〜っと伸びる
・レベルアップ時の派手な演出
```

#### 2. プログレスバー
```
種類：
A. 全体進捗
   「コース完了度：45%」

B. 章進捗
   「第3章：3/5セクション完了」

C. スキルツリー
   「営業スキル：初級→中級（60%）」

トランジション：
・セクション完了ごとにバー伸長
・視覚的フィードバック
・「あとちょっと！」感の演出
```

#### 3. バッジ・実績システム

**達成時の演出:**
```
[条件達成]
  ↓
[0.5秒：画面が明滅]
  ↓
[2秒：バッジ表示]
  ┌─────────────┐
  │  🏆         │
  │ 実績解除！  │
  │ 「初心者卒業」│
  │ 10回の研修完了│
  └─────────────┘
  効果音：ファンファーレ（短め）
  ↓
[バッジコレクション画面]
  獲得したバッジ一覧を表示
```

### 音響設計

```
効果音（SE）：
```

## スタイル11: 落語・プレゼンコメディ型

### コンセプト
**「笑いで学ぶ。記憶に残る教育は楽しい」**

### 適した用途
- 堅苦しいコンプライアンス研修
- セクハラ・パワハラ防止教育
- 失敗事例の共有
- 社内ルールの説明
- 新人向けオリエンテーション

### 映像言語の特徴

#### 落語スタイル

**1. 一人多役の演出:**
```
基本構成：
・語り手が複数の役を演じ分け
・座布団に座る（または立つ）
・カメラは基本固定
・身体の向きで役を切替

トランジション：
[役A（右向き）]
  「課長、これ見てください」
  ↓
[0.1秒：身体回転]
  ↓
[役B（左向き）]
  「お、いいねえ」
  ↓
[0.1秒：回転]
  ↓
[役A]
  「ありがとうございます！」
```

**2. 枕（導入）→本題→オチの構造:**
```
[00:00-00:30] 枕（日常話・共感）
  「みなさん、こんな経験ありませんか？」
  → 軽い笑い・うなずき
  ↓
[ディゾルブまたはカット 1秒]
  ↓
[00:30-03:00] 本題（教育内容）
  ストーリー仕立てで展開
  → 笑いながら学ぶ
  ↓
[0.5秒：溜め]
  ↓
[03:00-03:30] オチ（結論・教訓）
  「つまりね、___ってことなんです」
  → 納得と笑い
```

#### プレゼンコメディ（TED×お笑い）

**1. ツッコミ入りスライド:**
```
[スライド表示]
  「当社の売上推移」
  ↓
[プレゼンター]
  「ご覧ください、この素晴らしいグラフ...」
  ↓
[0.2秒：スライド変化]
  グラフが下降線に
  ↓
[プレゼンター]
  「...って、下がっとるやないかい！」
  （自分でツッコミ）
  ↓
[笑い]
```

**2. 失敗事例の再現ドラマ（コメディ風）:**
```
[ナレーション]
  「よくある失敗例」
  ↓
[早回し再現映像 0.5秒×5]
  ・メール誤送信
  ・会議寝落ち
  ・名前間違え
  ・締切忘れ
  → コミカルなBGM
  ↓
[スローモーション 2秒]
  決定的瞬間
  → 効果音：ズコー
  ↓
[解説]
  「こうならないために...」
```

### トランジション技法

**A. 「間」の使い方:**
```
[ボケ発言]
  ↓
[2秒：沈黙・カメラ固定]
  視聴者が笑う時間
  ↓
[次のシーンへ]

※エヴァの静止とは違う「笑いの間」
```

**B. リアクションカット:**
```
[発言者]
  「売上、3億円達成しました」
  ↓
[0.3秒：聞き手の驚き顔]
  ↓
[発言者]
  「...の目標に対し、50%でした」
  ↓
[0.3秒：聞き手のガッカリ顔]
```

**C. テロップツッコミ:**
```
[発言]
  「私、完璧主義なんです」
  ↓
[画面にテロップ]
  「（机の上ぐちゃぐちゃ）」
  ↓
[カメラパン→実際の机]
  散らかっている
  ↓
[笑い]
```
