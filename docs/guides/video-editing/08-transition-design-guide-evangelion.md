## 「庵野秀明メソッド」10の特徴

### 1. 静止画の多用
```
動かさない勇気：
・予算節約ではなく「演出意図」
・静止画で数秒〜数十秒
・緊張感・時間の引き延ばし
・視聴者に「考えさせる」時間

例：TV版第弐拾四話「最後のシ者」
→ ほぼ静止画のみで構成
```

### 2. テロップ・文字情報の過剰使用
```
画面を埋め尽くす文字：
・「OPERATION」「STAND BY」
・カウントダウン
・専門用語の羅列
・英語・日本語混在
・情報過多による緊張感

→ 採用PV的には「企業情報」「数字」の視覚化
```

### 3. 極端なカット長の対比
```
0.1秒のカット ⇔ 30秒の固定カメラ

例：使徒戦闘シーン
・高速カッティング（0.1-0.3秒）
・突然の長回し（10秒以上）
・視聴者の感覚を揺さぶる
```

### 4. カットイン（決定的瞬間の強調）
```
重要な瞬間の反復：
・同じシーンを異なるアングルで連続
・0.2秒×3-5回
・「これが重要だ」と叩き込む

例：「ヤシマ作戦」のライフル発射
→ 5アングル×0.2秒の連続カット
```

### 5. 実写映像の挿入
```
アニメ→実写→アニメ：
・現実世界への侵食
・メタ表現
・視聴者の没入を壊す→再構築

例：旧劇場版「Air/まごころを、君に」
→ 実写の映画館・観客席
```

### 6. 意図的な「間」と「沈黙」
```
音がない恐怖：
・BGMなし・SEのみ
・呼吸音・環境音だけ
・30秒以上の静寂
・不安感の増幅

例：使徒が動かない時間
→ 10秒以上固定カメラ＋静寂
```

### 7. 破壊的カメラアングル
```
通常の映画文法を無視：
・真上・真下
・極端な俯瞰・煽り
・意図的に見にくい構図
・不安定さの視覚化

例：天井を見上げるカット連続
→ 方向感覚の喪失
```

### 8. カウントダウン・時間の視覚化
```
緊張感の定量化：
・「残り0.09秒」
・「シンクロ率400%」
・「A.T.フィールド全開」
・数字による切迫感

→ 採用PVなら「成長率」「達成率」
```

### 9. 色彩の記号的使用
```
色による意味付け：
・赤：血・生命・危険
・青：冷静・計算・理性
・緑：自然・安全（LCL液）
・オレンジ：人工・セカンドインパクト
・白黒反転：精神世界

→ 一つの色が画面を支配
```

### 10. メタ的テキスト挿入
```
自己言及的テロップ：
・「次回予告」での本音
・「サービスサービス」
・製作状況の暴露
・視聴者への直接語りかけ

→ 採用PVなら「本音」「リアル」の表現
```

## カラーグレーディング（エヴァンゲリオン調）

### 5作品の色彩比較

| 要素 | 新海誠 | ジブリ | DB | DQ | **エヴァ** |

```
・青（レイ・月）: 冷静・人工・寂しさ
・オレンジ（セカンドインパクト）: 破滅・終末
・緑（使徒のコア）: 異質・未知
```

```
基本：
・彩度: 状況で極端に変化（-50%〜+30%）
・コントラスト: +40〜+50（極端）

・日常（S1-3）: 彩度低め・暗め

特殊効果：
```
