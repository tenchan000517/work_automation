2. **運命の振り向き** - 背中→振り向き→正面（風+髪なびき）
3. **希望への手** - 手を伸ばす→光に触れる→光粒子拡散
4. **歓喜の微笑み** - 真顔→微笑み→キラキラ発生
5. **決意の一歩** - 静止→足を踏み出す→風が吹く
6. **空を見上げる** - うつむき→顔を上げる→空を見上げる
7. **花びらの中で** - 花びら舞う中に立つ→一枚キャッチ
8. **雪の静寂** - 雪が静かに降る中、佇む
9. **光の覚醒** - 暗闘→光粒子が集まる→発光
10. **グリッチ転換** - デジタルグリッチ→安定→新しい画面

## 3. プロンプト構造設計

### 3バリアント構造（Image-to-Video対応）

```
┌─────────────────────────────────────────────┐
│ 開始フレーム（静止画生成用）                  │
│ - スタイル + 背景 + エフェクト初期 + 人物初期 │
│ - "single frame, still image"               │
├─────────────────────────────────────────────┤
│ 動画プロンプト（Image-to-Video用）           │
│ - スタイル + エフェクト動き + 人物動き       │
│ - "smooth motion, 4-second clip"            │
│ ※背景は開始フレームに含まれるため言及不要   │
├─────────────────────────────────────────────┤
│ 終了フレーム（静止画生成用）                  │
│ - スタイル + 背景 + エフェクト終了 + 人物終了 │
│ - "single frame, still image"               │
└─────────────────────────────────────────────┘
```

### プロンプト要素の順序

**推奨順序（専門家回答より）**:
1. スタイル基盤（画風）
2. 背景/環境（開始・終了フレームのみ）
3. エフェクト状態
4. 人物アクション/状態
5. カメラワーク（必要な場合）
6. 技術指定（品質、フレーム指定）

### 演出ごとのプロンプト例

#### 例: 覚醒の目開き

**開始フレーム:**
```
[style], [location], [time],
extreme close-up of face, eyes closed, peaceful expression,
soft light on eyelids, slight shadows,
single frame, still image, high quality, no text, no watermark
```

**動画プロンプト:**
```
[style],
eyes slowly opening over 2 seconds, pupils dilating,
light reflecting in eyes, awakening expression,
subtle camera push in,
smooth motion, 4-second clip, high quality, no text, no watermark
```

**終了フレーム:**
```
[style], [location], [time],
extreme close-up of face, eyes fully open, alert aware expression,
bright light reflected in pupils, determined look,
single frame, still image, high quality, no text, no watermark
```

## 4. テスト計画: 再現性検証のフロー

### テストサイクル

```
┌──────────────────────────────────────────────────────┐
│ Step 1: プロンプト作成                               │
│ - animePvEffectSettings.js の定義を更新              │
└──────────────────────────────────────────────────────┘
                    ↓
┌──────────────────────────────────────────────────────┐
│ Step 2: 開始フレーム生成テスト                       │
│ - Nanobanana / DALL-E / Midjourney で静止画生成     │
│ - 意図通りか確認                                     │
└──────────────────────────────────────────────────────┘
                    ↓
┌──────────────────────────────────────────────────────┐
│ Step 3: 動画生成テスト                               │
│ - KLING / VIDU / Runway で Image-to-Video           │
│ - 動きが意図通りか確認                               │
└──────────────────────────────────────────────────────┘
                    ↓
┌──────────────────────────────────────────────────────┐
│ Step 4: 結果評価・改善                               │
│ - 問題点をプロンプトに反映                           │
│ - Step 1 に戻る                                     │
└──────────────────────────────────────────────────────┘
```

### 評価基準

| 項目 | 評価ポイント |
|------|-------------|
| エフェクト再現 | 指定したエフェクトが出ているか |
| タイミング | 動きの速度・緩急が意図通りか |
| 人物アクション | 開始→動画→終了の一貫性 |
| 構図・カメラ | 指定したアングルになっているか |
| 品質 | アーティファクト、崩れがないか |

### テスト優先順位

1. **覚醒の目開き** - 最も使用頻度が高い
2. **決意の一歩** - カメラワーク検証
3. **空を見上げる** - パーン検証（一気に動く）
4. **花びらの中で** - パーティクル検証
5. 残りのプリセット
