# 演出シーン（アクセントシーン）専門家相談

## 目的

アニメPV制作において、シーン転換のアクセントとなる「演出シーン」のテンプレートを作成する。
視聴者の心を震わせる一瞬のカットを、AI動画生成・画像生成で再現可能な形で設計する。

## 制約条件

### キャラクター描写の原則
- **含めない**: 人物の「特徴」（髪の色、服装、体型）→ キャラクターシートで定義済み、参照画像として添付
- **含める**: 人物が「どのように存在するか」（アクション、表情、ポーズ、カメラアングル、照明）

### 出力形式
各演出テンプレートから以下の2つのプロンプトを生成する：
1. **開始フレームプロンプト** - Nanobanana/Midjourney用（静止画）
2. **動画プロンプト** - KLING/VIDU用（5-10秒の動画）

---

## 専門家への相談

### 専門家1: KLING/VIDU 動画生成AIプロンプトエキスパート

**質問**:
以下の演出シーンについて、KLING/VIDUで最も効果的な動画を生成するためのプロンプト構造を教えてください。

1. 動画プロンプトの最適な構造（要素の順序、重要度）
2. 動きの表現で効果的なキーワード
3. カメラワークの指定方法
4. 感情・雰囲気を伝える表現
5. 避けるべき表現や注意点

**対象演出シーン**:
- 目を開ける瞬間（ピーク演出）
- 振り向く瞬間（転換点）
- 手を伸ばす（希望・決意）
- 涙（感動のクライマックス）
- 笑顔になる瞬間（ハッピーエンド）

---

### 専門家2: Nanobanana 画像生成AIプロンプトエキスパート

**質問**:
キャラクターの一貫性を保ちながら、感情的なインパクトのある開始フレームを生成するためのプロンプト構造を教えてください。

1. キャラクター参照画像を使用する際の最適なプロンプト構造
2. 表情・感情の描写で効果的なキーワード
3. 構図・カメラアングルの指定方法
4. 照明・雰囲気の表現
5. 背景効果（花びら、光、パーティクル等）の組み込み方

---

### 専門家3: 映像クリエイター（CMディレクター/映画監督経験者）

**質問**:
視聴者の心を一瞬で掴む演出シーンの設計原理を教えてください。

1. 「ピーク」として使える最もインパクトのある演出パターン（5-10種）
2. 各演出の心理的効果と使用場面
3. カメラワーク・照明・タイミングの黄金律
4. 背景効果（花びら、光等）の効果的な使い方
5. 避けるべきクリシェや注意点

---

## 回答を元に作成するテンプレート構造

```javascript
{
  id: 'template_id',
  name: '日本語名',
  category: 'peak' | 'transition' | 'ending',  // ピーク/転換/締め
  description: '演出の説明（日本語）',

  // 映像演出の詳細設定
  direction: {
    cameraWork: 'カメラワークの詳細',
    lighting: '照明設計',
    timing: 'タイミング・テンポ',
    emotionalIntent: '狙う感情効果'
  },

  // 開始フレーム用（Nanobanana/Midjourney）
  startFramePrompt: {
    base: 'ベースプロンプト（スタイルは外部から注入）',
    composition: '構図指定',
    character: 'キャラクターの状態（特徴は含まない）',
    effect: '背景効果',
    mood: '雰囲気・照明',
    negative: 'ネガティブプロンプト'
  },

  // 動画用（KLING/VIDU）
  videoPrompt: {
    base: 'ベースプロンプト',
    action: '動きの詳細',
    cameraMove: 'カメラの動き',
    effect: '背景効果の動き',
    timing: 'テンポ・速度'
  },

  // 使用ガイダンス
  usage: {
    bestFor: ['適した用途1', '適した用途2'],
    pairsWith: ['相性の良いシーン'],
    avoid: ['避けるべき使い方']
  }
}
```
